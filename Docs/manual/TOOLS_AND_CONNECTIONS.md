# ツールと外部接続

[詳細マニュアルに戻る](MANUAL.md)

## AIがツールを使う条件

ツールは、記憶を読む、更新案を作る、Webを参照するなどのアプリ操作です。モデルのツール呼び出し対応、ルームの権限、接続先や対象資料の準備が必要です。

利用可能な定義は必要に応じて追加提示されます。能力の要求が成功しても、実際の作業が完了した意味ではありません。「アプリ設定 → 動作の確認」でツールの状態・結果を確認してください。

## カテゴリ別の権限

「ルーム設定 → ツール権限」でカテゴリごとの範囲を選び、保存します。

| 範囲 | 内容 |
| --- | --- |
| 停止 | 対象ツールを使わせない |
| 参照のみ | 読み取りを許可 |
| 参照・提案 | 読み取りと確認待ち案の作成を許可 |
| 参照・提案・直接更新 | 対応する直接更新も許可 |
| 毎回確認（個別申請） | ツール名・引数を指定した一回限りの承認を使う |

提案を許可しても、その提案の保存まで自動承認するわけではありません。Web参照など、読み取りでも外部通信を伴うものがあります。

この設定は、人の画面編集や自動検索・登録済み予約の一括停止スイッチではありません。自律行動には独自の許可も必要です。

## 個別の権限申請

1. 対象カテゴリを「毎回確認」にして保存します。
2. 通常会話でAIが申請を作ると、「個別の権限申請」に表示されます。
3. 理由・ツール名・引数を読み、一回承認または却下します。
4. 承認後、新しいメッセージで続きを伝えます。

**承認ボタンだけでは処理を開始しません。** 同じツール・同じ引数の一回の呼び出しに使います。期限は申請作成から1時間です。設定や定義の変更で無効になる場合もあります。

自律処理はこの一回承認を使って権限を拡張しません。失敗時の再試行も状態を確認してから新しい申請・承認を行います。

## Web検索・公開URL・PDF

「アプリ設定 → Web・画像生成」でWeb検索をテストできます。検索先はDuckDuckGo専用です。追加確認などで取得に失敗しても、別の検索元へ自動切替しません。「DuckDuckGoを開く」でブラウザから確認できます。

検索語やURLは外部へ送信します。公開ページの取得には制限があり、ログインが必要なページや任意のローカルファイルを読める機能ではありません。公開PDFの本文抽出には、形式やサイズの制限があります。

検索結果がないことだけで「情報が存在しない」とは判断できません。失敗・追加確認・未設定などの状態も確認してください。

## URL監視

「ルーム設定 → URL監視」で表示名・公開URL・グループ・頻度・時刻・日次上限を設定します。初期は停止・手動のみです。

定期取得にはURLの有効化と、自律設定のWeb許可が必要です。通常の定期自律や会話モデルの起動自体は、単純な取得に必須ではありません。差分のAI要約などを使う場合は、追加の設定・モデル条件に従います。

「一度だけ取得」で確認し、初回基準保存・変更なし・変更あり・取得失敗を見分けます。止める場合は有効を外して保存、保管する場合は「停止して保管」を使います。

## 画像生成

1. 「アプリ設定 → Web・画像生成」で方式を選びます。
2. 接続先URL、モデル名、キー、必要な生成条件を設定し、保存します。
3. 「世界・生活 → 画像生成」で本文・対象・参照画像などを確認して生成します。
4. ジョブの状態と生成画像を確認します。

方式にはローカル（SD WebUI / Forge）、Gemini、OpenAI互換、Pollinations、Hugging Faceがあります。ローカル方式も対応する別の画像生成サーバーが必要です。

接続先ごとの対応形式・認証・利用枠に従います。会話APIの設定とは別で、会話モデルを起動しただけでは画像生成できません。プロンプト編集・生成予約・画像完成・背景への反映も別の操作です。

## 音楽検索

「アプリ設定 → 音楽検索」で推薦リンクのサービスを選びます。YouTubeは常に有効です。音楽推薦は検索リンクを案内するもので、実在確認・再生・サービスのログインを完了する機能ではありません。

## 外部接続の設定場所

| サービス | 設定場所と範囲 |
| --- | --- |
| X / Twitter | 「外部接続 → X / Twitter」。1ルーム1アカウントを登録・認証 |
| Discord | 「外部接続 → Discord」。1ルーム1Botを登録・認証 |
| Googleカレンダー | 共通の認証は「アプリ設定 → 外部連携」。利用許可・操作は「外部接続 → Googleカレンダー」 |
| Gateway／Lite | 共通のサーバー・HTTPS・トークンは「アプリ設定 → 外部連携」。ルームの許可は「外部接続 → Gateway／Lite」 |

XとDiscordを共通側へ複数登録してルームで選択する方式ではありません。アカウントID、Botのチャンネル、必要な権限をルームごとに確認します。「接続確認・他ルームとの重複を確認」で同一アカウントなどの警告を確認できます。

OAuthや専用ブラウザでのログインを使う場合は、画面の手順に従って認証し、完了後に状態を確認してください。接続先の権限や認証状態によっては接続できない場合があります。

## 参照・送信案・実送信

外部接続では、参照と送信案の作成、確認後の送信を区別します。

1. 接続先とルームの利用設定を保存します。
2. 画面または許可されたAIツールで参照・送信案の作成を行います。
3. 送信先、本文、日時、添付、変更・削除対象を確認します。
4. 確認チェックと承認操作で実行します。
5. 履歴と必要に応じて外部サービス側で結果を確認します。

設定変更後の古い案は使えない場合があります。通信断などの「結果未確認」は自動再送しません。まず実サービス側を確認し、重複投稿・重複予定を避けてください。

Discordの受信開始・停止、REST受信／Gateway接続、自動返信はそれぞれ状態を確認します。**自動返信を明示的に許可した場合は、個別の送信確認を待たずに返信する経路があります。** 自動返信は初期OFFです。同一Bot・同一チャンネルの競合も確認してください。

## 認証情報と移設

会話APIや外部連携の対象認証情報はWindowsユーザー向けの暗号化を使います。別PC・別Windowsユーザーへコピーしても、そのまま使えないため再認証が必要です。画像生成など、別方式の保存もあるので設定フォルダ全体を秘密情報として扱ってください。

Gatewayは外部クライアント用です。通常の会話だけなら有効化は不要です。トークン・HTTPS・公開範囲・ルーム許可を確認してから利用します。

## 実行前後の処理と上限

AIは必要に応じて利用できるツールを確認します。ツールを使うと予告しただけでは操作完了ではありません。利用するにはルームの権限と接続設定が必要です。

カテゴリを要求した後に実処理をせず回答を終えたときは、対応条件のもとで一度だけ続行を促す経路があります。失敗/途中/結果未確認の更新を無条件に再送する仕組みではありません。能力要求すら起こさなかったすべての自然文を確実に拾う保証もありません。

通常会話では、ユーザーが操作を依頼し、AIがその操作の実行を予告したまま呼び出し0件で終えた場合にも、会話1回につき一度だけ穏やかな続行案内を送ります。画像生成・Web検索・短期メモの更新案などの明確な表現、またはツール名を明示した予告が対象です。相談・使い方の説明・追加質問・引用例などは対象から外します。必要な操作が現在利用できることが条件で、権限や提示範囲は広げません。案内後も予告だけならそこで終了します。自律処理や、すでにツールを呼んだ会話での再試行には使いません。表現によって検知できない場合があり、案内してもモデルが実行する保証はありません。

1回の会話で実行できるツールの件数や処理量には上限があります。複雑な依頼は、複数の会話に分けてください。失敗時に無制限に再試行することはありません。

カテゴリの直接更新許可と、確認待ち外部案の承認は別です。同じ操作の重複実行を防ぎ、保存競合・中止・結果未確認を成功として扱いません。

外部サービスの設定項目・操作引数は[外部接続タブ](main_tabs/EXTERNAL.md)、権限モードは[ルーム設定](main_tabs/ROOM_SETTINGS.md)、接続先の共通条件は[アプリ設定](main_tabs/APP_SETTINGS.md)にまとめています。

## 公開PDF本文取得の対応範囲

公開URLから取得したPDFの本文を抽出します。現行の主な上限はPDF本体1MiB・100ページ・抽出本文200000文字、抽出待機の既定12秒です。画像だけのPDFはOCRせず、暗号化PDF等はエラーになります。

## 画像生成の受付・完了・タイムアウト

会話の画像生成ツールは、生成先の応答と画像保存が終わるまで同じ呼び出し内で待機します。成功時は保存先と生成結果をAIへ伝えてから、同じ会話の回答生成を続けます。画面から手動で依頼する生成ジョブの受付と完了は別です。

「アプリ設定 → Web・画像生成」の生成APIの待機上限は30〜1800秒の整数。初期値はローカル600秒、外部180秒です。初回モデル読込に時間が必要な場合は増やせます。生成API応答の待機上限であり、結果URLからの画像取得など後続処理まで含めた全体秒数の厳密保証ではありません。

タイムアウトは「結果未確認」として保持します。生成先で処理が続く可能性があるため、自動再送はしません。画面では「タイムアウト（結果未確認）」を表示し、AIから受け付けたジョブは状態確認のポーリングでも通知します。

通常の次の会話には、同じルームで直近24時間にAIが受け付けた最大3件の状態・結果を渡します。元の画像プロンプトや認証情報は含めません。これは会話開始時点の状況で、途中に状態が変わることがあります。過去の会話の再生成には後からの状況を自動挿入しません。画像生成の履歴でも状態や経過時間を確認できます。

## ツール結果の受領と自動報告

通常のツールは、返された結果を次のAI生成へ渡してから応答を完了します。その生成が空またはエラーの場合は、アプリが受け取った状態と案内を会話欄に表示します。処理を再実行する仕組みではありません。

会話から呼ぶ画像生成・URL監視の即時取得・研究購読の即時実行は、要求した処理の結果を待ち、その処理の結果をAIへ伝えてからAIが続きを生成します。受付だけで会話を終え、後から別の報告を追加する方式ではありません。対応モデルには完成画像の実データも渡します。画像未添付では画像内容を確認した扱いにしません。

タイムアウト・失敗・中止もその状態を返し、成功した扱いにしません。中止後も生成先で処理が続く場合があるため、元の処理は自動再送しません。ツールの結果を渡した後のAI応答が空・通信エラーの場合は、アプリが確認済みの結果を表示します。

待機中は同じ会話を処理中として保持し、関係ない予約や他ルームのジョブを先に実行しません。確認待ち案の承認・外部送信の承認・タイマー等の発火を代行したり待ち続けたりすることはありません。

生成画像の保存先は`app/characters/<ルーム>/generated_images/<年月>/<生成先>_<ルーム名の小文字>_<Unix時刻>_<UUID>.png`などです。NexusArkと同じ命名要素を使い、拡張子は実画像の形式に従います。既存画像は改名しません。

更新後に新しく会話から生成した画像はAIの発言に紐づけて表示し、会話ログや再読み込み後も保持します。クリックで拡大できます。表示先はアプリが保存した画像IDから取得するため、AIが本文のファイル名や日時を書き間違えても影響しません。Markdown内の任意の画像を自動取得する設定ではありません。
