# はじめに・起動と終了

2026年11月1日版。

画面上部の本アイコン付き「マニュアル」ボタンから、このマニュアルを別タブで開けます。目次・本文リンク・見出しへの移動に対応し、元の会話や設定の編集中内容は保持します。保存済みの共通外観に、開いたルームの上書きを適用した色・フォント・文字サイズ・行間を使います。マニュアルのタブへ戻ると外観を読み直します。閲覧画面からの保存・AI呼び出しは行いません。

[詳細マニュアルに戻る](MANUAL.md)

初めてcloneした場合は、先に[利用準備と更新](INSTALLATION.md)で実行環境・モデルなどの必要ファイルを確認してください。

## 必要な環境

| 項目 | 内容 |
| --- | --- |
| OS | Windows 11 |
| Python | CPython 3.10.11（64bit）を同梱 |
| ブラウザ | Chrome、Edge、Firefoxなど |
| ローカル会話モデル | llama.cppが対応するGGUFを別途用意 |
| GPU・メモリ | モデルと設定に応じたRAM・VRAM。GPU利用時は対応ドライバー等 |

同梱の `app/runtime/python.exe` を使います。通常はPythonの別途インストール不要です。ファイルが見つからない場合は、clone・ダウンロード・展開が完了しているか確認してください。

```text
Akari-Chat/

```

アプリが書き込める場所へ配置します。モデルは外部フォルダに置いてパスを指定することもできます。

## 起動する

1. `Start.bat` をダブルクリックします。
2. コンソールが開き、ブラウザに画面が表示されるまで待ちます。
3. 自動でブラウザが開かない場合は、コンソールの表示URLを確認します。標準ポートは `8765` です。
4. [モデルと共通設定](MODELS_AND_SETTINGS.md) に従って会話モデルを準備します。
5. [ルームと会話](ROOMS_AND_CHAT.md) に従ってキャラクターを選びます。

画面はモデルの準備完了を待たずに開きます。画面が見えていても、読み込み中はまだ生成できません。「次回起動時にモデルを自動起動」が保存済みなら、次回から自動起動します。

同じインストールの二重起動はできません。すでに起動している場合は既存の画面を利用してください。

## 終了・再起動する

上部の終了アイコンを **1秒長押し** すると終了します。コンソールの `Ctrl+C` でも終了できます。ブラウザのタブを閉じるだけでは、アプリやモデルは終了しません。

再起動アイコンも **1秒長押し** です。保存済み設定で起動し直し、通常は同じブラウザタブを再読み込みします。

**長押しの終了・再起動では、未保存の本文や設定を保存する確認は出ません。未保存内容は破棄されるため、必要な内容を先に保存してください。** 実行中の生成には停止処理が入り、管理中の会話用・検索用モデルも終了対象になります。

コンソールの「×」や強制終了では、生成途中の本文が保存される保証はありません。通常の終了操作を使ってください。

## 自動起動やポートを変更して開く

`Start.bat` をメモ帳などで開き、次の設定を書き換えて保存してから、通常どおりダブルクリックで起動します。すでに起動中の場合は、一度アプリを終了してください。

```bat
set "NO_AUTO_START=N"
set "PORT=8765"
```

- **NO_AUTO_START**：`Y` または `y` にすると、会話・記憶検索モデルの自動起動を省略します。それ以外ではアプリに保存済みの自動起動設定に従います。モデルの起動で問題が出た場合に使います。
- **PORT**：ブラウザ画面の待受ポートです。通常は `8765`。他のアプリが使用中なら、例えば `8766` に変更します。空欄の場合は `8765` を使います。

NO_AUTO_STARTをYにしても、アプリに保存済みの自動起動設定は変更されません。原因を解消したらNに戻して保存します。Start.batに書いた指定は次回以降の起動にも適用されます。ポートを変えても、同じインストールの二重起動制限は解除されません。

## 起動・終了・起動設定の仕様

| 指定 | 指定場所 | 効果・反映時点 |
| --- | --- | --- |
| NO_AUTO_START | Start.bat内の設定 | Y/yの間は会話・検索モデルの自動起動を省略。保存済み指定を変更しない |
| PORT | Start.bat内の設定 | UIの待受ポートを指定。空欄は8765。同じインストールの二重起動を許可する指定ではない |

上部の再起動/終了は1秒長押しです。未保存内容の確認を出さず破棄します。ブラウザタブを閉じても本体は動き続けます。外部で独自起動した別のサービスを一括終了する機能ではありません。

状態表示はActive / Starting / Stopping / Inactive。外部会話APIでは接続方式名を付記します。これは外部APIの利用枠や次の回答の成功を保証する表示ではありません。

## 常設の表示・操作

| 場所・項目 | 動作 |
| --- | --- |
| 右ペインのROOM | 通常会話やルーム別画面の対象を切り替える。ルーム管理の独立選択とは別 |
| 左ペインの現在地 | 登録済み場所から選び、現在地と対応画像を表示する |
| Active等の状態 | 準備・起動・停止を確認する。外部APIの場合は接続方式を付記 |
| 再起動アイコン | 1秒長押し。未保存内容を破棄して保存済み状態で再起動 |
| 終了アイコン | 1秒長押し。未保存内容を破棄して本体と管理中プロセスを終了。ブラウザタブは残る |
| 手紙箱・通知 | アプリ内の手紙/お知らせを確認。外部への配信とは別 |
| ログを書き出す | 会話テキストを保存。添付本体を含む全体バックアップではない |

表示の短い完了メッセージと、永続の実行履歴・エラーログは別です。通知がフェードアウトしても履歴の成功/失敗状態は別途確認できます。
