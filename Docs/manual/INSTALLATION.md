# 利用準備と更新

2026年11月2日版。

[詳細マニュアルに戻る](MANUAL.md)

## 1. アプリのフォルダを確認する

Gitで取得したフォルダのうち、`Start.bat` と `app` がある場所を、この資料では「Akari-Chatフォルダ」と呼びます。取得したリポジトリによっては、その一つ下にAkari-Chatフォルダがあります。

まだ取得していない場合は、公開先の「Code」からコピーしたURLを使ってcloneします。すでに取得済みなら、この操作は不要です。

```powershell
git clone <公開先からコピーしたURL>
```

山括弧を含む部分は実際のURLに置き換えます。書き込み可能な場所へ配置してください。

## 2. 起動に必要なものを確認する

**公開版にはPython・追加機能用ライブラリ・llama.cppの実行ファイルを同梱します。GGUFモデルは別途用意してください。** cloneまたはZIP展開後、次のファイルと利用条件を確認します。

| 用意するもの | 必要になる場面 | 確認する場所・方法 |
| --- | --- | --- |
| Windows 11 | アプリの利用 | 他のOS向けの起動手順ではありません |
| Pythonの実行環境（同梱） | アプリの起動 | `app/runtime/python.exe`。通常はPythonの別途インストール不要 |
| ブラウザ | 操作画面 | Chrome、Edge、Firefoxなど |
| llama.cppの実行ファイルと必要なDLL（同梱） | ローカル会話・背景生成・記憶検索 | `llama.cpp/llama-server.exe`。DLLは同じ配布物・ビルドのものを使います |
| 会話用GGUF | ローカル接続での会話・自律行動、Discord自動返信など | `Models/LLM/`。モデルごとにサブフォルダを作成できます |
| 記憶検索用GGUF | 意味検索 | `Models/embeddings/`。キーワード検索だけなら不要です |
| 外部APIのキーと利用可能なモデル | 外部APIでの通常会話 | 起動後に「アプリ設定 → 会話モデル」で登録します |

`app/runtime/python.exe` やllama.cppの実行ファイルがない場合は、clone・ダウンロード・展開が完了しているか確認してください。Start.batだけを別の場所へコピーせず、フォルダ一式を保持します。通常の利用に、Pythonの別途インストールやソースの編集・ビルドは不要です。

Web検索・外部接続・PDF取得に使うライブラリは同梱します。各サービスの認証や、別途必要なアプリについては「追加機能を使う場合」を確認してください。

GGUFモデルは同梱せず、自動ダウンロードもしません。モデル配布元の利用条件と、必要なRAM・VRAMを確認して用意してください。同梱のllama.cppでは利用できないGPU・モデルを使う場合は、対応する推論エンジンを別途用意する必要があります。外部APIを設定すれば、通常会話と手動・定期・行動予約の自律行動はGGUFなしでも利用できます。研究購読・会話後の記憶処理・夜間整理の文章生成も外部APIを利用できます。埋め込み・検索・索引にはローカルの記憶検索モデルを使います。

## 3. 初回起動する

1. `Start.bat` をダブルクリックします。
2. コンソールとブラウザの画面が開くまで待ちます。
3. 「共通設定 → アプリ設定」でローカル会話モデル、または会話APIを設定して保存します。
4. ローカルの場合は「モデルを起動」を押し、Activeになるまで待ちます。
5. ROOMでキャラクターを選び、会話を送信します。

ローカルモデルを起動せず設定画面を開きたい場合は、`Start.bat` 内を `set "NO_AUTO_START=Y"` に変更して保存し、通常どおり起動します。

標準キャラが含まれる構成では、`app/characters` 内にフォルダが一つもない初回起動時にAssistantとAkariを用意し、Assistantを選択します。標準キャラの素材が含まれていない場合は簡易Assistantが作成されます。自分のキャラはルーム管理から作成・取り込みできます。

初回の標準キャラ配置時に、各草案の `data/ACTIVITY_PURPOSE.md` があれば「自律行動 → 活動記録 → 活動目的」に取り込みます。タイトル・本文・状態・次の一手と、価値観などの詳細欄へ対応付けます。取り込みは一度だけで、既存ルームの目的や編集済みの内容は上書きしません。活動目的の登録だけでは、定期自律は有効になりません。

起動・終了の詳しい操作は[はじめに](GETTING_STARTED.md)、GGUF・APIの設定は[モデルの設定](MODELS_AND_SETTINGS.md)を参照してください。

## 追加機能を使う場合

| 機能 | 追加で必要なもの |
| --- | --- |
| Web検索 | 検索用ライブラリは同梱。接続先の制限で失敗する場合もあります |
| Discordの常時接続 | 接続用ライブラリは同梱。Botトークンと必要なDiscord側の権限を用意 |
| XのCookie接続 | ブラウザ用ライブラリとPythonは同梱。Microsoft Edgeと有効な自分のCookieを用意 |
| 公開PDFの本文取得 | PDF用ライブラリは同梱。画像だけのPDFは対象外です |
| ローカル画像生成 | SD WebUI/Forgeなど、対応する画像生成サーバーの別途起動 |

必要ファイルが揃っていても起動できない場合や、特定の機能だけ使えない場合は、[困ったとき](BACKUP_AND_TROUBLESHOOTING.md)を確認し、エラー内容とアプリの版を添えて問い合わせてください。会話データや認証情報が入った他人の利用フォルダを、そのまま実行環境としてコピーしないでください。

## 更新する

1. アプリを通常終了し、[フォルダ全体をバックアップ](BACKUP_AND_TROUBLESHOOTING.md)します。
2. 公開先の更新案内に、追加の準備や移行手順がないか確認します。
3. cloneしたリポジトリのフォルダで `git pull --ff-only` を実行します。
4. 完了を確認してから `Start.bat` で起動し、ルーム・設定・会話を確認します。

更新がローカルの変更や履歴の違いで止まった場合は、その状態で中止し、エラー内容を確認してください。変更や利用データを消して更新を強制しないでください。Gitで更新しても、別途用意した実行環境やモデルまで自動更新されるわけではありません。
