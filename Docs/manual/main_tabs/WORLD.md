# 世界・生活タブ

[詳細マニュアルに戻る](../MANUAL.md#メニュー別リファレンス)

開く場所：右ペインの「ルーム別設定 → 世界・生活」。

## このメニューでできること

キャラとユーザーの所持品・衣装、世界の場所・背景、時間予約、手紙・通知、生成画像を扱います。

#### 所持品・衣装を変更する

所持先がユーザー・キャラ・場所のどれかを確認してから、品物と数量を選んで操作します。配置・回収では場所も確認します。削除・変更後の復元には操作前の履歴を使います。

ユーザーの衣装で「共通を使う」を選んでいると、共通の外見・衣装の編集が他の利用ルームにも影響します。キャラの衣装は別です。共通側のコピー・復元は「共通設定 → 共有データ」で行います。

#### 外見から画像用の文章を作る書式

保存書式は1〜6000文字。差し込みは `{appearance}`（基本外見）、`{note}`（装いの補足）、`{outfit}`（着用衣装）、`{extra}`（追加指定）です。外見・装い・衣装のいずれかを最低一つ含めます。式の評価、独自の書式指定、任意の変数名は使えません。

書式を保存する、過去の書式を編集欄へ読む、下書きを作る、ローカルモデルで文章を編集する、画像生成欄へ移す、生成する、対象画像を差し替える、という操作を分けます。書式を変えただけでキャラの外見や背景を変更しません。

### 場所・背景

エリア・場所・説明・現在地と背景画像。

#### 場所と背景を変更する

1. 「場所・背景」で世界設定を読み込み、既存の場所を選びます。
2. 左側のエリア・場所、右側の説明を確認・編集します。
3. 背景を選ぶと、その場でプレビューが変わります。場所を選んだときは対応画像があれば選択します。
4. 必要な保存・反映操作を行い、左ペインの現在地を確認します。移動は「この場所へ移動」で行います。

背景選択の初期値は「背景無し」です。プレビューを表示しただけでは保存されません。画像がなければ左ペインには代替記号を表示します。RAWを編集した場合は、構造化した場所一覧も読み直して確認してください。

#### 画像生成の受付・完了・タイムアウト

会話からの画像生成は、生成先の応答と画像保存が終わるまで待ってから、結果を元に回答を生成します。成功時はstate=succeeded、completed=trueと保存先・画像IDを返します。画面から手動で依頼する生成ジョブの受付と完了は別です。

「アプリ設定 → Web・画像生成」の生成APIの待機上限は30〜1800秒の整数。初期値はローカル600秒、外部180秒です。初回モデル読込に時間が必要な場合は増やせます。生成API応答の待機上限であり、結果URLからの画像取得など後続処理まで含めた全体秒数の厳密保証ではありません。

タイムアウトは「結果未確認」として保持します。生成先で処理が続く可能性があるため、自動再送はしません。画面では「タイムアウト（結果未確認）」を表示し、AIから受け付けたジョブは状態確認のポーリングでも通知します。

通常の次の会話には、同じルームで直近24時間にAIが受け付けた最大3件の状態・結果を渡します。元の画像プロンプトや認証情報は含めません。これは会話開始時点の状況で、途中に状態が変わることがあります。過去の会話の再生成には後からの状況を自動挿入しません。画像生成の履歴でも状態や経過時間を確認できます。

対応する会話モデルには完成画像も同じ応答内で渡します。別の発言として後から報告する方式ではありません。生成先の結果が不明な場合も、その結果を渡し、自動再送はしません。詳しくは[ツール結果の受領](../TOOLS_AND_CONNECTIONS.md#ツール結果の受領と自動報告)を参照してください。

保存先は`app/characters/<ルーム>/generated_images/<年月>/<生成先>_<ルーム名の小文字>_<Unix時刻>_<UUID>.png`などです。NexusArkと同じ命名要素で、拡張子は実画像の形式によります。元画像はSQLiteの中ではなく、ここに画像ファイルとして保存します。既存ファイルは改名しません。

新しく会話から生成した画像は、そのAI発言の画像として表示します。会話ログ、再読み込み、発言の退避・復元でも紐づけを維持します。本文中の推測ファイル名を解析せず、保存済み画像IDで表示します。クリックで拡大できます。

従来の180秒待機でTimeoutErrorが保存された履歴も、書き換えずにタイムアウトと分類して表示します。元の会話回答を遡って書き直したり、後から自動でAIの発言を生成したりはしません。

## 予約と画像生成を使う

通常のタイマーと、AIに作業を依頼する行動予約は別です。後者では日時・目的・具体的内容を入力し、実行履歴も確認します。会話中は待機し、PCやアプリを停止している間は実行できません。

画像生成は「アプリ設定 → Web・画像生成」で接続を準備してから使います。SD WebUI/Forgeは別の画像生成サーバーの起動も必要です。生成が完了したことと、背景やアイテムへ反映したことは別に確認します。
