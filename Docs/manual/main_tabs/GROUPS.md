# グループ会話タブ

[詳細マニュアルに戻る](../MANUAL.md#メニュー別リファレンス)

開く場所：右ペインの「共通設定 → グループ会話」。

## このメニューでできること

2〜8人のキャラを参加させ、順序を指定して会話します。グループ専用の設定とログを持ち、個別ルームの会話とは別に保存します。このメニューは1画面で操作できます。

## グループを作る

1. 「新規作成」を押し、グループ名を入力します。
2. 「参加者と発言順序」でキャラクターを追加し、順序を調整します。
3. 「グループを保存」を押します。
4. 「発言するキャラクター」で参加者全員、または特定の一人を選びます。
5. 本文を入力して「グループへ送信」を押します。

全員を選ぶと登録順に生成します。モデル/APIは各話者のルームの実効接続を使います。共通メニューにあっても、全員が一つのルームのAPIを使うわけではありません。

## 履歴と設定を管理する

「最新の会話を表示」「前の40件」で履歴を確認します。発言内の操作で編集・再生成・選択以降の削除を行えます。「最新のログ操作を戻す」で直前の操作の復元を行います。再生成は対象の話者一人について行います。

「このグループを保管」を指定して保存すると利用対象から外せます。個別ルームの保管とは別です。参加者に保管中ルームがある場合は、復元してから生成を始めます。

## 個別会話との違い

各キャラは自分の設定・記憶と共有会話を使います。他キャラの個別会話を混ぜたり、グループログを個別ルームの自動記憶処理に転記したりしません。

グループではツール呼び出し・画像入力を使いません。停止や失敗では完了済みの発言と途中の本文を保持し、後続の生成を止めます。全員の回答完了と、一人目だけの完了を区別してください。
