# 会話タブ

[詳細マニュアルに戻る](../MANUAL.md#メニュー別リファレンス)

開く場所：右ペインの「ルーム別設定 → 会話」。

## このメニューでできること

選択中のキャラとの会話、画像の添付、回答生成の停止、発言の編集・再生成・選択以降の削除ができます。このメニューは1画面で操作できます。

## 会話を始める

1. 右ペインのROOMで相手のルームを選び、「会話」を開きます。
2. 上部の接続状態を確認します。ローカルならモデルの起動・準備を待ち、外部APIなら有効な接続とモデルを設定します。
3. 本文を入力し「送信」またはEnterを押します。改行はShift+Enterです。
4. 生成中は待機表示が動きます。生成中は入力欄の「送信」が「中止」に切り替わります。中断するときはこの「中止」、「生成を停止」、またはEscキーを使います。

会話モデルを変更する場所は「共通設定 → アプリ設定」。このルームだけ接続を変える場所は「ルーム設定 → 会話API」です。通常の自律行動で生成した発言もAI側に表示されます。

## 発言の操作

発言に付くアイコンを使います。アイコンの説明と、確認画面の対象範囲を読んで実行します。

| 操作 | 対象と結果 |
| --- | --- |
| ユーザー本文の編集 | 変更を確定して後続の会話を退避し、回答を作り直します |
| AI回答の再生成 | 選択した回答以降を退避して再生成します。過去の回答を選んだ場合も後続が対象です |
| 削除 | 選択した発言を含む、それ以降の会話を対象にします。本文の部分削除ではありません |

本文だけの修正、変更履歴からの復元、過去の検索には「会話ログ」を使います。会話の変更は、すでに保存した記憶や外部送信の巻き戻しにはなりません。

## 画像・Markdown

画像は添付ボタン、貼り付け、ドロップで追加します。添付内容と送信対象を確認してください。対応する画像モデルと、ローカルの場合は対応mmprojが必要です。

本文はMarkdown表示に対応します。Markdown内の画像は自動取得しないので、AIに見せる画像には添付機能を使います。編集すると元のMarkdownを編集できます。

## 表示・保存の見方

AIの日時は回答終了時で、モデル名も表示します。ユーザー発言にはモデル名を付けません。外部APIから本文が返らなかった場合は、その旨のメッセージを表示します。停止・失敗・結果未確認は完了と区別してください。

画面で見えている履歴の範囲と、モデルへ送る直近メッセージ数は別です。送信設定を増やす操作は「アプリ設定 → 会話モデル」で行います。

関連：[ルームと会話](../ROOMS_AND_CHAT.md) / [画像と添付](../IMAGES_AND_ATTACHMENTS.md)

## 画面項目の詳細

次の入力条件は画面側の制約です。保存時には対象の存在・形式・競合なども検査します。「初期値」は未設定時に使われる値を記載しています。既存ルームや取込済み設定の表示値とは異なる場合があります。

### 会話の項目

| 項目 | 意味・変更時の動作 | 初期値 | 入力条件・選択肢 |
| --- | --- | --- | --- |
| 会話へ添付する画像 | 会話に添付する画像を選びます。実際の送信前にプレビューと対象を確認します。 | 既存値/対象に従う | 複数選択可 |
| メッセージ | 選択中ルームへの発言。Enterで送信、Shift+Enterで改行します。 | 既存値/対象に従う | 書式・保存条件は本文参照。対象の既存値を読み込む項目は固定初期値なし |

操作ボタン：

| 操作 | 作用・確認点 |
| --- | --- |
| 画像を添付 | 対象の一覧・資料・履歴・表示を確認または切り替えます。表示だけで原本保存が完了したことにはなりません。 |
| 送信 ↗ | 対象の一覧・資料・履歴・表示を確認または切り替えます。表示だけで原本保存が完了したことにはなりません。 |

Escキーは、画面に表示されている有効な生成中止ボタンと同じ処理を実行します。会話・再生成・グループ会話と各種生成画面で利用できます。画像の拡大表示などのダイアログが開いている場合は、そのダイアログを閉じる操作が優先されます。日本語入力の変換中とキーの長押し連打では生成を中止しません。生成中でない場合は中止要求を送りません。既に開始したツールの外部処理が取り消せるかは、従来の中止処理の制限に従います。

中止したAIの途中回答は、末尾を改行して「（中断されました。）」を付けて保存します。会話ログや再読み込み後も残ります。通常完了・エラー終了の本文には付けません。既存ログは書き換えません。

入力欄のボタンは、生成が完了または中止すると「送信」に戻ります。生成中の入力欄でEnterを押しても、中止や新しい送信は行いません。中止要求の送信中は連打を受け付けず、入力中の次のメッセージは保持します。
