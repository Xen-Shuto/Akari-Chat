# 共有データタブ

[詳細マニュアルに戻る](../MANUAL.md#メニュー別リファレンス)

開く場所：右ペインの「共通設定 → 共有データ」。

## このメニューでできること

ルームをまたいで使う共有手順と、ユーザーの共通クローゼットを管理します。特定ルームの記憶やキャラの所持品をすべて共通化する画面ではありません。

## 各タブの案内

### 共有手順

全ルーム向けの作業方法を保存し、ルーム用の下書きへコピー。

#### 共有手順を作る

1. 「共有手順」で新規作成、または既存の手順を選びます。
2. タイトル・本文・適用条件・手順・成功条件を入力します。手順は1行1件、10件までです。
3. 状態を確認して「全ルーム共通として保存」を押します。
4. 特定ルームで使う場合はROOMを確認し、「このルームの手順の下書きにコピー」を押して、コピー先で確認・保存します。

ルーム側から共通の下書きへコピーする経路もあります。コピー後は独立しており、自動同期しません。手順の文章を保存しただけで、コードの実行やツール権限の追加は行われません。

共有前に、特定キャラの秘密、個人情報、関係が他ルームへ渡る内容になっていないか確認してください。

### 共通クローゼット

共通使用中ルームのユーザー外見・衣装・着用状態を管理。

#### 共通クローゼットを使う

1. コピー元のルームをROOMで選びます。
2. 「共通クローゼット」で、置き換える対象と他ルームへの影響を確認します。
3. 確認チェックを入れ、「このルームの専用設定を共通へコピー」を押します。
4. 利用する各ルームの「世界・生活 → 衣装・外見」で「このルームで共通を使う」を選びます。

共通使用中の外見・衣装の編集は、他の共通使用中ルームにも反映します。ルーム専用へ戻すと保持していた専用設定を使います。キャラクター側の衣装・所持品、生成画像との関連付けは別です。

#### 履歴から戻す

共通の操作前の状態を選び、「共通の状態を復元」で戻します。復元も共有データの置換なので、利用中の他ルームへの影響を確認してから行います。
