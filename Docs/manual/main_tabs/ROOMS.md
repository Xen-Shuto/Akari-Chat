# ルーム管理タブ

[詳細マニュアルに戻る](../MANUAL.md#メニュー別リファレンス)

開く場所：右ペインの「共通設定 → ルーム管理」。

## このメニューでできること

ルームの新規作成、表示名・説明の編集、保管・復元、キャラ作成補助、既存キャラの取込、NexusArk向け書出しを行います。

**ルーム一覧の対象は「管理するルーム」で選びます。右のROOMとは独立しているので、保存前に対象を確認してください。**

## 各タブの案内

### ルーム一覧

新規作成・基本情報の編集、保管・復元。

#### 作成・編集する

単純にルームを作る場合は「ルーム一覧」で新しいルームを選び、フォルダ名・表示名・説明・指示を入力して保存します。フォルダ名は作成後に変更できません。表示名や説明は編集できます。

キャラを一緒に考える場合は「キャラ作成」で名前・役割・性格・話し方・関係などを入力します。AIの候補は選んで採用し、指示やコアを確認し、必要なら試し会話をしてから作成します。

AI補完と試し会話は、右のROOMの会話接続を使います。外部APIの利用時には入力した案等を外部へ送信します。

#### 保管・復元・書出し

保管はデータを削除せず通常一覧と背景処理の対象から外します。最後の利用中ルームは保管できません。復元後は予約・自律設定も確認します。

NexusArk書出しは対象と内容を確認してから行い、Exports/NexusArk配下へ新規フォルダを作ります。既存NexusArkルームへの自動上書き・差分統合はしません。完全な往復やアプリ全体のバックアップを保証する機能ではありません。

関連：[ルーム・取込・書出しの詳細](../ROOMS_AND_CHAT.md) / [ルーム別の設定](ROOM_SETTINGS.md)

#### ルーム一覧の項目

| 項目 | 意味・変更時の動作 | 初期値 | 入力条件・選択肢 |
| --- | --- | --- | --- |
| 管理するルーム | 管理対象のルーム。右ペインのROOMとは別に選べます。 | 既存値/対象に従う | 対象一覧から選択（読込内容により変化） |
| フォルダ名 | 新規ルームのフォルダ名。既存ルームでは変更しません。 | 既存値/対象に従う | 画面入力 80文字まで |
| 表示名 | 画面に表示するキャラクター/ルーム名。フォルダ名とは独立です。 | 既存値/対象に従う | 画面入力 200文字まで |
| 説明 | 左ペインのキャラ名下へ表示する説明文。SystemPromptの全文ではありません。 | 既存値/対象に従う | 画面入力 4000文字まで |
| キャラクター指示 | 通常のルーム新規作成で保存するキャラクター指示です。 | 既存値/対象に従う | 画面入力 100000文字まで |
| 確認用のフォルダ名 | 保管/復元対象のフォルダ名を再入力して操作対象を確認します。 | 既存値/対象に従う | 書式・保存条件は本文参照。対象の既存値を読み込む項目は固定初期値なし |

操作ボタン：

| 操作 | 作用・確認点 |
| --- | --- |
| 新しいルーム | 対象の一覧・資料・履歴・表示を確認または切り替えます。表示だけで原本保存が完了したことにはなりません。 |
| 再読込・未保存の変更を破棄 | 編集中の変更を捨て、表示を初期化または保存済み内容を読み直します。 |
| 保存 | 選択中の対象へこの操作を行います。対象・内容・確認欄・履歴を確認し、競合/結果未確認の場合は再実行前に実体を調べます。 |
| このルームを保管 | 選択中の対象へこの操作を行います。対象・内容・確認欄・履歴を確認し、競合/結果未確認の場合は再実行前に実体を調べます。 |
| このルームを復元 | 選択中の対象へこの操作を行います。対象・内容・確認欄・履歴を確認し、競合/結果未確認の場合は再実行前に実体を調べます。 |

### キャラ取込

room_config.jsonを基準にキャラフォルダをコピー。

#### 既存キャラを取り込む

「キャラ取込」でroom_config.jsonをファイルピッカーまたはパス直入力で指定し、「取り込む」を押します。元フォルダは変更せずコピーします。同名なら別名になります。ファイル選択だけでは取込しません。

NexusArkの共通設定・すべての内部状態を取り込む機能ではありません。取込後は会話API・ツール権限・索引・画像を確認してください。

#### キャラ取込の項目

| 項目 | 意味・変更時の動作 | 初期値 | 入力条件・選択肢 |
| --- | --- | --- | --- |
| room_config.jsonのパス | コピー元のroom_config.json。直入力またはファイルピッカーで指定します。選択だけでは取り込みません。 | 既存値/対象に従う | 書式・保存条件は本文参照。対象の既存値を読み込む項目は固定初期値なし |

操作ボタン：

| 操作 | 作用・確認点 |
| --- | --- |
| ファイルを選択 | 対象の一覧・資料・履歴・表示を確認または切り替えます。表示だけで原本保存が完了したことにはなりません。 |
| 取り込む | 対象の一覧・資料・履歴・表示を確認または切り替えます。表示だけで原本保存が完了したことにはなりません。 |

### NexusArk書出し

新しいエクスポートフォルダへキャラ構成を組み立て。

#### NexusArk書出しの項目

| 項目 | 意味・変更時の動作 | 初期値 | 入力条件・選択肢 |
| --- | --- | --- | --- |
| 書き出すルーム | 「書き出すルーム」の対象を一覧から選びます。履歴・候補の選択だけでは保存・復元・実送信を実行しません。対応する操作ボタンで確定します。 | 既存値/対象に従う | 対象一覧から選択（読込内容により変化） |
| 私的な文章も含まれることと、表示された対象・制限を確認しました | 私的文章も含む書出し対象と制限を確認します。書出し先は新規フォルダで、既存NexusArkルームは上書きしません。 | 既存値/対象に従う | ON/OFF |

操作ボタン：

| 操作 | 作用・確認点 |
| --- | --- |
| 書き出す内容を確認 | 対象の一覧・資料・履歴・表示を確認または切り替えます。表示だけで原本保存が完了したことにはなりません。 |
| 新しいフォルダへ書き出す | 対象の一覧・資料・履歴・表示を確認または切り替えます。表示だけで原本保存が完了したことにはなりません。 |
| 書出しを中止 | 対象の実行/受付を止めます。途中結果や外部送信の確定状況は履歴で確認します。 |
