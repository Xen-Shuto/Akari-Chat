# ルーム設定タブ

[詳細マニュアルに戻る](../MANUAL.md#メニュー別リファレンス)

開く場所：右ペインの「ルーム別設定 → ルーム設定」。

## このメニューでできること

ROOMで選んだルームの接続上書き、人格の検査条件、画像、検索索引、ツール権限、自動処理、外観を設定します。「ルーム管理」の作成・保管とは別の画面です。

## 各タブの案内

### 会話API

共通接続の継承、またはこのルーム独自の接続・認証・モデル。

#### 共通を引き継ぐか決める

会話APIは通常「共通設定に従う」を使います。独自接続にしたいときは継承を外し、設定して「このルームの接続を保存」を押します。外観は上書きする項目だけルームを優先します。共通を使う項目は共通設定の変更に追従します。

会話APIの接続は手動・定期・行動予約の自律行動にも使います。研究購読・会話後の記憶処理・夜間整理の文章生成も同じ接続を使います。埋め込み・検索・索引はローカルです。ローカルのモデル起動条件自体は「アプリ設定」で管理します。

#### Persona Contractの保存制限と検査結果

用語・呼び名・口調ルールは各200文字・40件以内、契約全体はJSON表現で12000文字以内です。画面の各欄の入力上限10000文字とは別に保存時の検証が入ります。名前は各200文字、検査文は20000文字までです。

重大度はerror/warning/info。既定は、禁止語がerror、必須語・呼び名・口調ルールがwarningです。errorの違反があると検査のpassedはfalseになります。warningがあってもpassedはtrueの場合があります。「合格」は口調・人格の意味的な適合を保証しません。

禁止語・使わない呼び名の包含、必須語の不在、推奨呼び名が一つもないことを文字の一致で検出します。口調は手動確認のリストとして返し、AIで自動添削しません。保存時は元の設定が変更されていないか確認し、バックアップを作成します。

#### アバターの表示方式と優先順位

自動/プロフィール/固定表情などを選択できます。管理する8枠はprofile・idle・thinking・neutral / joy・anger・anxious・sadnessです。通常待機はidle、通常会話生成中はthinking、回答後は明示表情タグ等を使います。自動表示では待機復帰時間や内部状態連動も設定できます。

登録済みの管理画像と、キャラ原本からの発見画像を区別します。avatarフォルダの状態に合う表情を優先し、なければprofile等に代替します。avatarが空/存在しなければルーム直下を探し、候補がなければ装飾記号です。削除は管理上の非表示化で、原本画像の物理削除とは異なります。

外観の全項目は[アプリ設定](APP_SETTINGS.md)を参照してください。ルームでは上書きした項目だけが共通より優先されます。

#### 静止画の切り抜きダイアログ

| 項目 | 初期値・範囲 | 意味 |
| --- | --- | --- |
| 拡大率 | 1、1〜4、刻み0.1 | 切り抜き対象を拡大 |
| 横の位置 | 50、0〜100 | 表示範囲の左右位置を調整 |
| 縦の位置 | 50、0〜100 | 表示範囲の上下位置を調整 |

切り抜きの確認・登録を行ってから管理枠へ反映します。GIF/動画はこの静止画切り抜きの対象外です。ファイルを選ぶだけ、プレビューだけ、登録完了を区別してください。

#### 独立している夜間設定

夜間自動実行の有効化、記憶種類、週次/月次圧縮、案の自動保存、索引更新、同名研究の統合、完全重複エンティティ整理、エンティティ休眠はそれぞれの設定です。「夜間自動実行OFF」だけですべてが止まると解釈しないでください。

睡眠時間は「自律行動 → 実行設定」で管理し、初期OFF、00:00〜07:00が標準です。通常の定期自律・短いお知らせの抑制と、夜間の記憶整理がこの時間帯を共有します。各処理は対象条件・使用中保護・原本版の一致を確認し、失敗/競合/結果未確認で保存を強行しません。


#### 睡眠時間外に手動で整理する

「手動の記憶整理」で、夜間の自動実行がOFFでも実行できます。会話モデルまたは会話APIと、ローカルの記憶検索モデルを先に設定してください。

- **差分を整理する**：前回の整理位置から、ボタンを押した時点までの完了した会話を整理します。5件未満の残りも対象です。未完了のユーザー発言や、開始後に増えた会話は次回に回します。
- **退避して全会話から再整理**：確認欄をONにして実行します。過去の整理で作った記憶を退避し、元の入力状態へ戻してから、会話ログ全体を読み直します。会話ログは削除しません。生成履歴と原本バックアップで由来を確認できる記憶だけを対象とし、手編集が混在する場合は上書きせず停止します。

どちらも会話を小分けにして、日記・エピソード・夢日記・永続記憶・短期メモの5種類を順に保存し、最後に意味検索の索引を更新します。この操作自体が保存の指示になります。通常の夜間実行の対象チェック・案の自動保存OFFには連動しません。コアメモリ・人格は変更しません。週次/月次圧縮、研究・エンティティ整理などの独立した処理は従来の設定どおりです。

実行の受付時に、対象ルームの自動想起・知識の自動参照、RAG・意味検索・統合案の自動反映、保存後の索引更新をONで保存します。また、共通の「次回起動時に検索モデルも起動」「自動想起で意味検索を使う」もONで保存します。モデルのパスや数値のしきい値は変更しません。

退避先は `app/data/manual_memory_backups/<実行ID>/` です。履歴にも表示され、保存前の各ファイルと照合用の一覧が残ります。通常の原本バックアップも維持します。

「手動整理を中止」では保存済みの記憶とキャッシュを保持します。失敗・中止・結果未確認では、履歴とAI更新案を確認してから「結果を確認して続行」を押します。保存済みの案は重ねて生成しません。準備中に失敗した場合は自動復旧せず、退避先・設定・原本を確認して「準備失敗を確認済みにする」で確認を記録します。途中の整理がある場合は新規の受付を止め、続行時点の設定を確認してから未完了の段階を進めます。資料の競合がある場合は、AI更新案と原本を先に確認してください。

索引更新だけが失敗しても、先に保存した記憶は残ります。「完了」と表示されるまでは索引を含めた成功扱いにはなりません。文章生成には選択中の会話接続を使い、埋め込み・索引作成はローカルで行います。

## よく使う設定の流れ

- 表情：4列×2行の各枠で画像を登録します。上段profile / idle / thinking / neutral、下段joy / anger / anxious / sadnessです。表示候補がなければ従来の画像優先順位で代替します。
- 意味検索：共通で検索モデルを起動してから、このタブの「記憶索引」を作成・更新します。本文保存の完了と索引更新の完了を別に確認します。
- AI操作：権限カテゴリと許可範囲を決めて保存します。個別承認は承認ボタンだけで実行されず、通常会話で続きを依頼します。
- 夜間整理：睡眠時間は実行設定で管理し、夜間整理は初期無効です。対象と許可を確認して有効化し、履歴とAI更新案を確認します。

設定を選んだだけでは保存されない項目があります。保存後の完了表示を確認します。接続先・アカウントの設定は「外部接続」、全体の検索エンジン本体や外観の基本値は「アプリ設定」にあります。
