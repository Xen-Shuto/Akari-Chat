# ルームと会話

[詳細マニュアルに戻る](MANUAL.md)

## ルームを作る

ルームは、キャラクターの設定・記憶・個別会話を扱う単位です。

1. 「ルーム管理 → ルーム一覧」で「新しいルーム」を選びます。
2. フォルダ名・表示名・説明・キャラクター指示を入力します。
3. 「保存」を押し、作成したルームを選びます。

フォルダ名は作成後に変更できません。表示名と説明はルーム一覧から、指示は「記憶・知識 → キャラクター指示」から編集できます。

指示には人柄・口調・関係・守ってほしいことを書きます。案内役には、実行できない操作を「完了した」と言わない指示も役立ちます。

## キャラ作成アシスタントを使う

「共通設定 → ルーム管理 → キャラ作成」で名前・人柄・口調・関係などを入力し、指示やコアの案を確認して新しいルームを作れます。AI補完・試し会話は、右のROOMで選択中のルームの会話接続を使います。既存キャラの指示・記憶・会話をそのまま送る機能ではありません。外部APIなら入力案を外部へ送信します。

作成前に案を読み、保存先と名前を確認してください。

## NexusArkのキャラを取り込む

1. 「ルーム管理 → キャラ取込」を開きます。
2. 「ファイルを選択」で元キャラの `room_config.json` を選ぶか、パスを入力します。
3. 「取り込む」を押します。

JSONのあるキャラクターフォルダをコピーし、原本は変更しません。同名があれば別名になります。ファイルを選んだだけでは取り込みません。

アプリ停止中に `app/characters/` へキャラフォルダを直接コピーすることもできます。起動後に表示を再読み込みしてください。

対応する設定・指示・記憶・ログを読みますが、NexusArkの共通設定やすべての内部状態を継承するものではありません。新しい会話はあかりのDBに保存し、コピー元のログには追記しません。

## 会話する

1. 右側でルームを選びます。
2. ローカルモデルまたはAPI接続の準備を確認します。
3. 「会話」の入力欄にメッセージを書きます。
4. 「送信」またはEnterで送ります。改行はShift+Enterです。

途中で止めるときは「生成を停止」を押します。途中の回答は状態付きで保存される場合があります。完了と途中停止・失敗を区別して確認してください。

画像の利用は [添付管理](IMAGES_AND_ATTACHMENTS.md) を参照してください。AIへ作業を頼む場合も、権限・接続条件が必要です。返答だけで実行成功と判断せず履歴を確認します。

## Markdownと会話の表示

会話・会話ログは、見出し、強調、箇条書き、引用、表、コードブロックなどを表示します。編集時は元のMarkdownを編集します。HTMLを実行せず、Markdown内の画像を自動取得しません。リンクを開く操作と、画像を会話に添付する操作は別です。

生成中は待機表示が動き、回答後には日時とモデル名を表示します。AIの日時は回答終了時です。ユーザー発言にはモデル名を付けません。通常の自律行動の発言もAI側へ表示されます。外部APIが空の回答を返した場合は、その旨を括弧付きのメッセージで表示します。

## ログを読む・検索する

「会話ログ」は通常、最新100発言を表示します。「さらに古い100件」で過去へ移動できます。検索後は一致する発言を選び、前後の会話を確認します。「最新100件を表示」で検索を解除します。

表示範囲とモデルへ送る直近メッセージ数は別です。保存済みログがすべて毎回送られるわけではありません。

## 本文修正・再生成・削除・復元

発言内のアイコンから操作します。メインの会話画面ではユーザー本文の変更と再生成、選択以降の削除、AI再生成を行います。会話ログでは文脈を見ながら本文のみの修正や変更履歴の復元も行えます。表示される対象範囲を確認してください。

| 操作 | 結果 |
| --- | --- |
| 本文を修正 | ユーザー・AIの本文を変更。これだけで自動生成はしません |
| ユーザー発言を変更して再生成 | 後続を退避し、変更した発言に対する回答を生成 |
| AI回答を再生成 | 選択した回答以降を退避して作り直す |
| 選択した発言以降を削除 | 選択した発言を含む後続を通常の表示・送信対象から除外 |
| 変更履歴から復元 | 現在の対象範囲も退避して、選択した変更前の会話へ戻す |

会話の復元は、作成済み記憶・ノート・外部投稿の一括巻き戻しではありません。各管理画面も確認してください。

## ログを書き出す

上部の「ログを書き出す」でテキストを保存できます。画像名は記録しますが、画像本体を含むバックアップにはなりません。NexusArkで使う際は発言ヘッダーや取り込みプレビューを確認します。

## ルームの保管・復元

「ルーム管理 → ルーム一覧」で対象を選び、確認欄にフォルダ名を入力して保管・復元します。

保管すると通常の選択・背景処理の対象から外れ、ファイル・会話・設定・予約を保持します。最後の利用中ルームは保管できません。復元後は期限を過ぎた予約が動く場合があるため、予約・自律設定を確認してください。

## グループ会話

1. 「グループ会話」でグループ名と2～8人の参加者を登録します。
2. 発言順を調整し、保存します。
3. 「発言するキャラクター」で全員または1人を選び、送信します。

全員なら登録順に生成します。会話APIは各話者のルーム設定を使います。共有ログは個別ルームの会話と別に保存します。

各キャラは自分の設定・記憶と共有ログを使い、他キャラの個別会話は混ぜません。グループではツール・画像入力を使いません。共有会話を個別ルームの自動記憶処理へ転記することもありません。

共有ログにも編集・再生成・選択以降の削除・最新操作の復元があります。AI回答の再生成は対象話者1人です。停止・失敗時は完了済みの発言と途中の本文を保持し、後続を止めます。保管中の参加者がいれば、ルームを復元してから開始します。

## NexusArk向けに書き出す

「ルーム管理 → NexusArk書出し」で対象を選び、「書き出す内容を確認」へ進みます。私的文章・制限の説明を読み、確認して実行します。

`Exports/NexusArk/` の新しいフォルダへ原本と現在の会話・所持品・衣装・表情などを組み立てます。NexusArkの既存ルームへの自動上書きや差分統合は行いません。

内部DBの全状態、接続・権限、タイマー、画像のモデル再入力構造などの完全変換には対応しません。アプリ全体のバックアップとしては使わず、NexusArkへの配置前にも内容を確認してください。NexusArk上での実動作確認は未完了です。

## 本文・履歴・設定の保存先を区別する

個別会話はapp/data/chat.sqlite3のルーム別レコードとして保存します。キャラフォルダの月次ログへ毎回二重追記する方式ではありません。グループログは独立し、個別会話へ自動転記しません。

本文のみの修正は生成しません。ユーザー編集からの再生成、AI再生成、選択以降削除は後続に影響します。変更前を退避するログ操作と、外部送信や記憶保存の履歴は別です。
