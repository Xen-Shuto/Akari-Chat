# 会話の画像と添付管理

[ユーザーガイドに戻る](USER_GUIDE.md)

## 画像を添えて送信する

画像対応のモデル・接続先を準備します。ローカルでは対応する本体と必要なmmprojを設定してください。

1. 「会話」で「画像を添付」を押すか、入力欄へ画像を貼り付け・ドロップします。
2. サムネイルを確認し、不要な画像を送信前に外します。
3. 本文を入力して送信します。画像だけでも送れます。
4. サムネイルを押すと拡大表示できます。

PNG・JPEG・WebPを受け付け、ブラウザで長辺2048px以下のPNG/JPEGに変換します。保存するのは変換後の画像です。

| 制限 | 上限 |
| --- | --- |
| 元画像 | 1枚20MiB・約3200万画素 |
| 変換後 | 1枚5MiB |
| 1リクエスト | 4枚・合計12MiB |

テキスト用モデルに切り替えても履歴は残りますが、新しい画像入力には画像対応が必要です。会話への音声・動画入力には対応していません。アバターの動画表示とは別の機能です。

## 過去の画像を再利用する

「ルーム設定 → 添付画像」で、このルームの送信済み画像を確認します。絞り込み・ページ移動後に画像を選んで操作します。

| 操作 | 内容 |
| --- | --- |
| プレビュー | 画像を拡大して確認 |
| 元の発言を見る | 会話ログで前後を確認。退避中の発言は対象外 |
| 入力欄へ再添付 | 新しい送信用の下書きに追加。これだけでは送信しません |
| 会話から外す | 履歴表示・履歴画像送信などから除外。画像本体は保持 |
| 会話へ戻す | 正常な画像を再び会話で使える状態に戻す |

発言の復元と画像の復帰は別です。発言を戻しても、管理画面で外した画像を自動では戻しません。表示される登録時サイズ合計も、実際のディスク占有量そのものではありません。

## 継続添付

「上で選択した画像を継続して使う」で、既存の添付を最大4枚指定できます。以降の会話で同じ画像を継続して参照させたいときに使います。

手動添付、継続添付、直近履歴の順で最大4枚・12MiBに収めます。手動添付が優先され、超過分はその回だけ省略されます。テキストモデルでは継続画像を省略します。自律・グループには自動送信しません。

解除しても過去の発言との関連は残ります。画像を会話から外すと継続選択も解除され、画像を戻しても継続選択は戻りません。欠損・変更の警告が出た場合は解除または再指定してください。

## 退避・復元・完全削除

「添付画像」の「画像ファイルを退避・完全削除する」から操作します。

1. 会話から外した画像を選び、退避します。
2. 必要なら退避一覧から復元します。会話から外した状態は維持します。
3. 容量を回収する場合は、確認のうえ退避画像を完全削除します。

**退避だけでは容量は減りません。完全削除した画像の実体は、この画面から復元できません。** 後から発言を復元しても画像本体は戻りません。既存バックアップ中のコピーまで消す操作ではありません。

結果未確認がある場合の「未確認の実体を照合する」は、元・退避先の状態を確認して記録する操作です。警告を確認せず何度も削除・復元を繰り返さないでください。

会話の添付、キャラのアバター、背景、生成画像は別の管理対象です。この画面ですべての画像を削除するわけではありません。
