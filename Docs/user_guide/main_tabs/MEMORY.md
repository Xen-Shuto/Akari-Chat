# 記憶・知識タブ

[ユーザーガイドに戻る](../USER_GUIDE.md#メニュー別ガイド)

開く場所：右ペインの「ルーム別設定 → 記憶・知識」。

## このメニューでできること

キャラクターの指示、各種の記憶・ノート・知識資料を読み書きし、検索・整理・AI更新案の反映を行います。操作対象はROOMで選んだルームです。

## 各タブの案内

### 検索

記憶・知識・過去会話などをキーワード/意味検索。

### RAG・意味統合

検索方針・意味の近い記憶の統合候補などを設定。

### キャラクター指示

基本の振る舞い・口調・行動ルールを編集。

### コアメモリ

会話の土台にする重要事項を編集。

### 永続記憶

継続して保持する情報を編集。

### 日記

年月・エントリを選んで記録を編集。

### エピソード

年月・エントリを選んで出来事の記憶を編集。

### 夢日記

年月・エントリを選んで内省や指針を編集。

### エンティティ記憶

人物・物・概念など対象別の記録を編集。

### 統合履歴

エンティティ統合の結果や状態を確認。

### 創作ノート

年月・エントリを選んで創作の記録を編集。

### 分析ノート

年月・エントリを選んで研究・考察を編集。

### 知識資料

参照用のTXT/Markdown資料を編集。

### 短期メモ

一時的に覚えておきたい本文を編集。

### 選択中の話題

現在使うワーキングメモリを編集。

### 話題の切替・作成

話題を作成・選択・休眠/復帰、自動選択を設定。

### 会話から記憶を作る

会話から草案・分類案を生成して保存。

### 旧主記憶の整理

旧形式の主記憶から移行用の追記案を作成。

### 睡眠時の整理

記憶整理案や圧縮などを実行。

### 日記アーカイブ

期間を指定した日記の要約・退避・原本更新。

### AI更新案

AIが提案した変更を確認・編集・反映。

タブは1行の横スクロールです。見えない項目は横へ移動して選びます。

## 記憶を編集する

1. 対象のタブを開きます。
2. 日記などは年月とエントリ、資料などは対象ファイルを選びます。コアメモリ・永続記憶・短期メモは決まった本文を開きます。
3. 本文を編集して保存します。
4. 完了表示を確認します。意味検索にも反映する場合は「ルーム設定 → 記憶索引」の更新状態を確認します。

別の画面や外部エディターで同じ資料が変わった場合は、現在の本文を読み直して差分を確認します。未保存の破棄は、編集中の内容を捨てる操作です。

## 検索・草案・自動処理の使い分け

「検索」で見つけた結果は、それだけで次の会話へ添付されません。会話中の自動想起は別設定です。意味検索には共通の検索モデルとルームの索引が必要です。

AI草案を作った後は「AI更新案」などで内容を確認して反映します。自動草案・分類・保存・索引更新はそれぞれ独立した設定です。一つを有効にしても他が全部有効になるわけではありません。

## 注意すること

保存された記憶すべてを毎回全文送るわけではありません。直接送信と検索抜粋を区別し、「アプリ設定 → 動作の確認」で送信内訳を確認します。整理・統合前には対象と保存先を確認し、原本のバックアップも保管してください。
