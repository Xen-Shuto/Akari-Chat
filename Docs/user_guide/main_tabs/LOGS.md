# 会話ログタブ

[ユーザーガイドに戻る](../USER_GUIDE.md#メニュー別ガイド)

開く場所：右ペインの「ルーム別設定 → 会話ログ」。

## このメニューでできること

選択ルームの会話を、前後の文脈を見ながら閲覧・検索・編集します。メインの「会話」と同様に発言を並べて表示します。このメニューは1画面で操作できます。

## 過去の会話を探す

1. ROOMを選び、「会話ログ」を開きます。
2. 通常は最新100発言を表示します。「さらに古い100件」で過去へ進みます。
3. 検索語を入れて「検索」を押します。
4. 一致した発言を選び、前後の会話を確認します。
5. 検索を終えるときは「最新100件を表示」を押します。

表示件数と、モデルへ送る直近メッセージ数は別です。古い会話を画面で開いただけで、次の生成へ全件送信されるわけではありません。

## 発言を修正する

| 操作 | 内容 |
| --- | --- |
| 本文のみの編集 | ユーザー/AIの文章を修正。これだけでは回答を生成しません |
| ユーザー発言を変更して再生成 | 後続を退避し、修正した発言から回答を生成 |
| AI回答の再生成 | 対象の回答以降を退避して生成し直す |
| 選択以降の削除 | 選択発言を含む後続を表示・送信対象から外す |

発言内のアイコンと確認内容を見て操作します。Markdown表示中も、編集欄では元の文章を変更します。通常再生成の対象外となる発言もあります。

## 変更前の状態へ戻す

「変更履歴から復元」で変更前の履歴を選び、内容を確認して「以降の会話を退避して変更前に復元」を実行します。現在の対象範囲も退避して戻します。

会話の復元は、記憶ファイル、外部投稿、予定、アイテム操作の一括巻き戻しではありません。会話を修正した後は、その会話から作った記憶・AI更新案も必要に応じて確認します。

## 書き出しとバックアップ

上部の「ログを書き出す」で会話テキストを保存できます。画像本体や設定・記憶すべてを含むバックアップではありません。完全な保管にはアプリ停止後のフォルダ全体コピーを使います。
