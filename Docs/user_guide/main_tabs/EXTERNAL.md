# 外部接続タブ

[ユーザーガイドに戻る](../USER_GUIDE.md#メニュー別ガイド)

開く場所：右ペインの「ルーム別設定 → 外部接続」。

## このメニューでできること

このルームで利用する外部アカウント、参照・投稿先、利用許可を設定し、参照結果や送信案を管理します。会話LLMの外部APIとは別です。

## 各タブの案内

### X / Twitter

投稿方針の要約と投稿ガイドラインは、Xの投稿ツールを提示するときにAIへ渡します。自動投稿は既定でOFFです。ONにしても、自動送信には外部接続の書き込み権限が必要です。公式APIの引用・返信は既定で承認待ちになります。X Premiumは手動設定で、ONにするとあかり側の通常投稿の文字数制限を緩和します。接続先による制限は引き続き適用されます。

「Discordに承認依頼を通知」は既定でOFFです。設定したルームのDiscordメインチャンネルへ通知し、ボタンはユーザID本人のみ操作できます。ボタンの受信にはGateway常時接続が必要です。「詳細」を押すと、本人だけに投稿本文と添付画像が表示されます。長文は全文をテキストファイルで表示します。確認したらDiscordの通知で「承認して投稿」または「却下」を選びます。

接続方式や認証情報は「設定」タブで管理します。設定を保存した後、公式APIでは「API接続テスト」、Cookieでは「セッション状態確認」で、認証中のアカウントを確認できます。

「投稿・承認待ち」タブの「承認待ちを更新」で、このルームの投稿案を表示します。一覧のIDを選ぶと本文と添付画像を確認できます。送信先と内容の確認にチェックを入れて「承認して投稿」を押すか、「却下」を選びます。「投稿履歴」では投稿済み・却下・失敗・結果未確認などの送信記録を確認できます。

**Cookie取り込みはXの非公式な接続方式で、利用は推奨しません。公式APIの利用を推奨します。Cookie方式の利用によりアカウントが制限・凍結される可能性があります。利用は自己責任となり、アカウントの凍結などによる不利益について、Akari-Chatの開発者は責任を負いかねます。**

1アカウントの登録・認証、利用条件・参照/送信案。

### Discord

1Botの登録・認証、チャンネル、受信・返信条件。

### Googleカレンダー

利用許可・カレンダーID、参照・予定案。共通側は「アプリ設定 → 外部連携」で準備します。

### Gateway／Lite

このルームへのアクセス許可。共通側は「アプリ設定 → 外部連携」で準備します。

X/Discordは一つのルームで複数アカウント/Botを同時に扱いません。共通に複数登録して選ぶ構成でもありません。

## 設定・接続を確認する

1. ROOMとサービスを選び、必要な認証・接続情報を入力します。
2. このルームでの利用条件を確認して保存します。
3. 「接続確認・他ルームとの重複を確認」などの操作で、認証状態・権限・競合を確認します。
4. まず必要な参照を試し、対象アカウント・チャンネル・カレンダーを確認します。

他ルームに同じアカウント/Bot等が登録されていないかのチェックは、実際の利用先を確認するためのものです。警告が出たら登録内容を見直します。

## 送信するとき

参照、送信案の作成、確認後の実送信を区別します。送信先・本文・日時・添付・変更/削除対象を読み、画面の確認操作を行ってから実行します。案の作成成功は投稿や予定の登録成功ではありません。

Discordの自動返信は独立した初期OFF設定です。有効化すると、条件に合う受信へ個別確認なしで返信する経路があります。受信開始/停止、REST/Gateway、対象チャンネル、モデルの準備をそれぞれ確認します。

## エラー・結果未確認

通信断などで結果未確認になった場合は、実サービス側と履歴を確認します。重複送信を避けるため、確認前に同じ操作を繰り返さないでください。別PC・別Windowsユーザーへの移設後は認証の再登録が必要な場合があります。

URL監視は「ルーム設定」、Web検索/PDF取得や画像生成の共通接続は「アプリ設定 → Web・画像生成」です。DuckDuckGoをブラウザで使えても、アプリからは取得できない場合があります。

関連：[ツールと外部接続の詳細](../TOOLS_AND_CONNECTIONS.md) / [ルーム別設定](../ROOM_SETTINGS.md) / [アプリ設定](APP_SETTINGS.md)

Discordはルーム内でBotを設定します。利用許可ON・Gateway常時接続の場合は起動時に受信を開始し、自動返信の生成中は入力中表示を更新します。日次上限は0で無制限です。サーバー・許可済みチャンネル・任意の宛先を一覧から選択できます。受信と送信成功した発言は本体にも表示しますが、本体の会話をDiscordへ自動転送しません。

Discord返信でも記憶・ノート・場所・所持品・予約など、ルームで利用可能なツールを使えます。必要なカテゴリを追加して実行結果を受け取り、確認待ちの更新や外部送信はアプリ側の承認まで保留します。参照したルーム内情報は返信に使用されるので、ツール権限は運用に合わせて設定してください。

日次上限が0以外で上限に達した場合は、対象メッセージへ上限と翌日0:00（日本時間）のリセットを知らせます。この通知はAI生成を使わず、応答枠にも含めません。

Discordへの返信待ち・回答生成・送信中は、選択中ルームの会話欄にも点滅表示します。自動表情のthinkingにも対応し、処理が終わると表示を解除します。

Discordを有効にする場合は「デフォルトのチャンネルID」と、あかり利用者本人の「ユーザID」が必須です。ほかのチャンネルは「許可するチャンネルID」、本人以外にBotへ話しかける人は「許可するユーザID」へ追加します。追加ユーザーが空欄なら本人だけが対話できます。既存設定も、この2つの必須IDを入力して保存してください。操作時にチャンネルIDを省略するとデフォルトを使います。
