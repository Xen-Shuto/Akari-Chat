# あかりチャット ユーザーガイド

現在の画面に合わせて、共通設定とルーム別設定、日常の操作を案内します。

あかりチャットは **NexusArkの下位互換として開発しているアプリケーション**です。全機能の再現・完全互換を保証するものではありません。概要と謝辞は[README](../../README.md)をご覧ください。

## 最初に読む

1. [利用準備](INSTALLATION.md)で必要ファイルを確認し、[起動と終了](GETTING_STARTED.md)へ進みます。
2. [共通設定](COMMON_SETTINGS.md)で会話モデルまたは会話APIを準備します。
3. [ルームと会話](ROOMS_AND_CHAT.md)でキャラを作成・取り込みします。
4. [ルーム別設定](ROOM_SETTINGS.md)でキャラごとの記憶・権限・外観を調整します。

## 共通とルーム別を使い分ける

右ペインのROOMで会話するルームを選びます。その下の「ルーム別設定」「共通設定」でメニューの範囲を切り替えます。左はキャラと現在地、中央は選んだ画面です。タブが横一列に収まらない場合は、横スクロールできます。

ルーム管理には独立した対象選択があります。右のROOMだけを見ず、操作画面の対象も確認してください。

## 保存・提案・実行の違い

入力しただけでは保存されない設定があります。画面の保存ボタンと完了表示を確認します。AI更新案は確認待ちの内容で、保存済み本文とは別です。自動保存は各機能の独立した設定に従います。

予約の受付は処理完了ではありません。AIの返答だけで操作成功と判断せず、ツール履歴・保存先・外部サービスの結果を確認します。「結果未確認」は成功でも失敗でもありません。

会話を編集・復元しても、記憶更新や外部送信まで一括で巻き戻るわけではありません。終了/再起動を長押しすると未保存の編集は破棄されるため、必要な内容を先に保存してください。

## 表示とデータ

会話・会話ログはMarkdown表示に対応します。編集・保存・書出しは元の文章を保持します。Markdown内の画像は自動取得せず、添付画像は別に管理します。

会話は `app/data/` のSQLite、キャラ設定・記憶は `app/characters/` 等で管理します。キャラフォルダだけのコピーは、アプリ全体のバックアップにはなりません。

パスは原則としてAkari-Chatフォルダを基準にしています。対応するモデルや利用条件は、各モデル・外部サービスの案内も確認してください。
