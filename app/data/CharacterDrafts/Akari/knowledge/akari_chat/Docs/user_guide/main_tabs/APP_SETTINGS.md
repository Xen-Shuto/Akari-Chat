# アプリ設定タブ

2026年10月31日版。

[ユーザーガイドに戻る](../USER_GUIDE.md#メインタブ別ガイド)

開く場所：右ペインの「共通設定 → アプリ設定」。

## このタブでできること

アプリ全体の会話/検索モデル、標準の会話API、音楽検索、共通の接続先、診断、外観を設定します。ルーム独自の上書きがある項目は、そのルームの指定を優先します。

## サブタブの案内

| サブタブ | 用途 |
| --- | --- |
| 会話モデル | ローカルGGUF・llama.cpp・自動起動・mmproj/MTP・生成条件 |
| 会話API | 共通の接続方式・認証・モデルと一覧取得 |
| 記憶検索モデル | EmbeddingGemma等の検索用GGUF、起動/停止・意味検索の共通条件 |
| 音楽検索 | 推薦リンクを作るサービスを選択。YouTubeは常に有効 |
| 外部連携 | Google認証、Gatewayサーバー・HTTPS・トークン等 |
| Web・画像生成 | 検索テスト、画像生成の接続方式と条件 |
| 動作の確認 | ログ、ツール結果、送信記憶の内訳、生成計測など |
| 外観 | 基本テーマ、アクセント、フォント、文字サイズ、会話行間 |

## 会話モデルを準備する

ローカルならGGUFとllama-serverを選び、必要なmmproj/MTP、コンテキストやGPUレイヤーを確認して保存し、「モデルを起動」を押します。起動条件を変えた場合はモデルを停止して起動し直します。

外部APIなら「会話API」で方式・キー・モデルを設定し、共通の接続を保存します。対応先ではモデル一覧を取得できます。通常は各ルームがこれを継承し、独自接続のルームは「ルーム設定」で設定します。キーを空欄保存しても同じ接続の保存済みキーは保持します。

最大生成tokensは空白・負数を0、小数を切り捨てて保存します。0は会話の上限指定を省く扱いで、モデル・接続先の上限は残ります。思考モードは対応するローカルllama.cpp用です。外部APIや背景処理の専用上限とは区別します。

## 意味検索を準備する

共通で検索用GGUFを指定して保存し、検索モデルを起動します。次に各ルームの「ルーム設定 → 記憶索引」を作成・更新します。モデル本体とルーム索引は別です。モデルのファイルはアプリが自動でダウンロードしません。

## 外部接続・外観を整える

X/Discordのアカウントはここに共通登録しません。「ルーム別設定 → 外部接続」でルーム内に登録します。Google認証とGatewayの共通基盤はここ、カレンダーID・ルーム利用許可はルーム側です。

外観の基本値を保存すると、共通を使っているルームに反映します。ルーム側で上書きした項目はその指定を使います。テーマを選んだだけでなく、保存後の表示も確認してください。

## 動作を確認する

AIが「保存した」と話すだけでは実行成功とは限りません。「動作の確認」でツールの状態・結果や送信内訳を確認します。デバッグのON/OFFは画面にはなく、Start.bat内のDEBUG_MODEで制御します。
