# 自律行動タブ

2026年10月31日版。

[ユーザーガイドに戻る](../USER_GUIDE.md#メインタブ別ガイド)

開く場所：右ペインの「ルーム別設定 → 自律行動」。

## このタブでできること

会話していない間のキャラの活動、目的・研究・問い、実行の許可と履歴を管理します。睡眠時の記憶整理とは別の仕組みです。

## サブタブの案内

| サブタブ | 用途 |
| --- | --- |
| 活動記録 | 目的・目標・研究・手順・振返りなどを管理 |
| 実行設定 | 定期実行・間隔・日次上限・処理上限・許可、動機などを設定 |
| 書き置き | 自律実行に渡すユーザーからのメモ |
| お知らせ設定 | 自律から手紙/短いお知らせを残す許可と表示を控える時間帯 |
| 実行履歴 | 待機・実行中・完了・失敗・中止・結果未確認を確認 |
| 行動の過程 | 活動に関係する記録や処理の流れを確認 |
| 目的の提案 | AIによる活動目的の変更案を確認・承認/却下 |
| 問いの進展 | 回答・部分回答・反証等の案や根拠を確認 |
| 研究検索 | 研究スレッドを検索・参照 |
| 研究購読 | 研究テーマの定期/手動取得とレポートを管理 |

## 最初に試す

1. 共通のローカル会話モデルを準備します。会話APIの設定だけでは背景生成はできません。
2. 「活動記録」に目的や関心、取り組みたい内容を用意します。
3. 「実行設定」で許可と上限を確認し、まず手動実行で動作を確かめます。
4. 「実行履歴」と会話欄を見て、実行結果・発言・更新案を確認します。
5. 定期実行したい場合だけ有効化し、間隔などを保存します。

初期は定期OFF、間隔30分、1日6回、120秒、512tokensです。間隔は最短5分、日次上限0は無制限です。動機判定や実行待ちなどもあるので、待機時間が過ぎれば必ず発言するわけではありません。

## 会話との順序と結果の保存

通常会話を優先し、会話中・会話待ちに新しい自律処理を始めません。自律処理の途中に発言した場合は、その処理を完了してから会話を開始します。

通常の自律や行動予約で生成した発言は会話欄にもAIとして表示・保存します。架空のユーザー発言は追加しません。夜間整理など内部処理の出力をすべて流す仕組みではありません。

記憶更新案を作る許可と、保存の承認は別です。実際のツール結果や保存状態を確認してください。段階ごとの文脈は必要な情報で組み直しますが、上限なしの生成ではありません。

## 止めたいとき・動かないとき

定期自律をOFFにしても、研究購読・夜間整理・URL監視・会話後の記憶処理が一括で停止するわけではありません。それぞれの設定を確認します。

実行されない場合は、モデル、保管状態、日次上限、待機中会話、実行中処理、結果未確認、動機の条件を確認します。結果未確認を成功扱いにして再送しないでください。

夜間の00:00〜07:00という標準時間帯は「ルーム設定 → 夜間の記憶整理」で管理します。自律のお知らせを控える時間帯とも別です。
