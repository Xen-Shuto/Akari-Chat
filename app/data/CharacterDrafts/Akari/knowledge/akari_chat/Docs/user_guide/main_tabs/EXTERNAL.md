# 外部接続タブ

2026年10月31日版。

[ユーザーガイドに戻る](../USER_GUIDE.md#メインタブ別ガイド)

開く場所：右ペインの「ルーム別設定 → 外部接続」。

## このタブでできること

このルームで利用する外部アカウント、参照・投稿先、利用許可を設定し、参照結果や送信案を管理します。会話LLMの外部APIとは別です。

## サブタブと共通側の準備

| サブタブ | このルームで設定するもの | 共通側 |
| --- | --- | --- |
| X / Twitter | 1アカウントの登録・認証、利用条件・参照/送信案 | 共通アカウント登録なし |
| Discord | 1Botの登録・認証、チャンネル、受信・返信条件 | 共通Bot登録なし |
| Googleカレンダー | 利用許可・カレンダーID、参照・予定案 | アプリ設定 → 外部連携で認証を準備 |
| Gateway／Lite | このルームへのアクセス許可 | アプリ設定 → 外部連携でサーバー・HTTPS・トークンを準備 |

X/Discordは一つのルームで複数アカウント/Botを同時に扱いません。共通に複数登録して選ぶ構成でもありません。

## 設定・接続を確認する

1. ROOMとサービスを選び、必要な認証・接続情報を入力します。
2. このルームでの利用条件を確認して保存します。
3. 「接続確認・他ルームとの重複を確認」などの操作で、認証状態・権限・競合を確認します。
4. まず必要な参照を試し、対象アカウント・チャンネル・カレンダーを確認します。

他ルームに同じアカウント/Bot等が登録されていないかのチェックは、実際の利用先を確認するためのものです。警告が出たら登録内容を見直します。

## 送信するとき

参照、送信案の作成、確認後の実送信を区別します。送信先・本文・日時・添付・変更/削除対象を読み、画面の確認操作を行ってから実行します。案の作成成功は投稿や予定の登録成功ではありません。

Discordの自動返信は独立した初期OFF設定です。有効化すると、条件に合う受信へ個別確認なしで返信する経路があります。受信開始/停止、REST/Gateway、対象チャンネル、モデルの準備をそれぞれ確認します。

## エラー・結果未確認

通信断などで結果未確認になった場合は、実サービス側と履歴を確認します。重複送信を避けるため、確認前に同じ操作を繰り返さないでください。別PC・別Windowsユーザーへの移設後は認証の再登録が必要な場合があります。

URL監視は「ルーム設定」、Web検索/PDF取得や画像生成の共通接続は「アプリ設定 → Web・画像生成」です。DuckDuckGoの原因調査は保留で、ブラウザで使えることだけではアプリからの取得成功を保証しません。
