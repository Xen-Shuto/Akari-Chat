# 自律行動と予約

2026年10月31日版。

[ユーザーガイドに戻る](USER_GUIDE.md)

## 最初に知っておくこと

背景の生成にはローカル会話モデルを使います。会話用APIの設定だけでは準備できません。アプリやPCが停止している間に、アプリが自らPCを起動・復帰させることもありません。

会話中・会話待機中には新しい自律処理を始めません。すでに自律処理が動いているときに発言すると、その処理の終了後に会話を始めます。待機中の会話より次の自律処理を先に始めません。

**定期自律のOFFは、すべての自動処理の一括停止ではありません。** 研究購読、夜間整理、URL監視、会話後の記憶処理などはそれぞれ独立設定を確認してください。

## 活動記録

「自律行動 → 活動記録」で目的・目標・研究スレッド・手順・振返りを管理します。状態や優先度、本文を確認して保存します。

目的は行動の軸です。価値観、関心、望む行動・避けたい行動、探求中の問いなども整理できます。AIからの目的変更は「目的の提案」で確認し、編集して承認するか却下します。

手順は作業方法の文章です。保存するだけで任意コード実行や権限付与が行われるものではありません。

## 自律実行を設定する

1. ローカル会話モデルを起動します。
2. 「自律行動 → 実行設定」を開きます。
3. 間隔、1日の上限、時間上限、生成上限を確認します。
4. Web参照・外部参照・更新案作成・活動更新の許可を選びます。
5. 必要な場合だけ「定期的な自律実行を有効にする」をオンにし、保存します。
6. 実行履歴で結果を確認します。

定期実行は初期OFFです。初期値は30分間隔・日本時間で1日6回・120秒・512tokensです。間隔は最短5分、1日の上限は0で無制限にできます。手動実行も許可範囲や日次上限に従います。動機判定などの条件により、間隔が経過しても必ず活動するわけではありません。

権限を追加しただけで外部送信まで無条件に許可されるわけではありません。ツール権限・接続設定も必要です。通常の自律実行や行動予約で生成した発言は、実行履歴に加えて会話欄にもAIの発言として表示・保存します。架空のユーザー発言は追加しません。夜間整理など内部処理の出力をすべて通常会話へ流す仕組みではありません。

## 文脈と生成上限

自律の段階を進める際は、人格・コアなどと必要な引継ぎ情報を使って文脈を組み直します。過去の全段階を無制限に積み増す方式ではありません。段階ごとの生成上限やコンテキストの余裕によって停止・短縮することがあります。通常会話の最大生成tokensを0にしても、自律処理の上限は別です。

## 実行履歴と行動の過程

「実行履歴」で待機・実行中・成功・失敗・中止・結果未確認などを確認します。「行動の過程」では、記録された関連情報や処理の流れを参照できます。

再起動前に実行中だった処理などは結果未確認になり、人の確認まで同ルームの背景処理が待機することがあります。保存先と履歴を確かめて確認済みにします。確認済みにするだけで同じ操作を再実行したり、成功に変更したりはしません。

## 研究と問い

- **研究を検索**：同ルームの研究スレッドを探し、本文や関連記録を確認します。
- **研究購読**：進行中の研究へテーマ・情報源・頻度を設定し、手動または日次／週次で実行します。初期は停止・手動のみです。
- **問いの進展**：AIが出した回答・部分回答・反証などの案と、根拠の引用を確認します。自動判定は独立設定です。
- **研究の整理・統合**：対象本文や購読の移管先を確認して実行します。自動適用・夜間整理を使う場合は個別設定と履歴も確認します。

研究購読は定期自律がOFFでも有効化したものが動きます。Web情報源にはWeb許可が必要です。止める場合は有効チェックを外して保存、保管する場合は「停止して保管」を使います。

ローカル研究購読のレポート自動追記は独立した初期OFF設定です。正常終了と参照結果・本文の版一致などを確認して追記します。Web購読では有効にできません。購読実行が完了しても、研究本文へ自動保存されたとは限らないため、レポートの状態を確認します。

## 共有手順とユーザーからの書き置き

「共有データ → 共有手順」で全ルーム用の手順を管理します。ルームの手順から共通の下書きへ、または共通からルーム用の下書きへコピーできます。コピー後は独立しており、自動同期しません。

共有前にキャラ固有の関係・秘密・個人情報を本文から除くか確認してください。自動で除去する仕組みではありません。

「自律行動 → 書き置き」ではユーザーからのメモを管理します。保存した内容は通常の自律実行に渡し、通常会話・研究購読・URL監視には自動挿入しません。自動消去しないため、不要になったら空欄にして保存します。通知設定や手紙箱とは別の入口です。

## 動機・感情・共鳴の追加設定

「実行設定」には、動機による定期実行の判定、感情と記憶の連携、反復評価、記憶の共鳴、日別Arousal、内部状態のリセットがあります。

多くは独立した初期OFF設定です。感情タグやArousalはモデルの自己申告などに由来する内部指標で、人の感情を測定した値ではありません。引用付きのユーザー感情推定も推定として扱います。

内部状態のリセット前には対象一覧を確認します。会話・記憶・実行履歴を削除する操作ではありません。「未解決の問いも保管する」は追加の対象指定です。

## 夜間の記憶整理

1. 「ルーム設定 → 夜間の記憶整理」を開きます。
2. 日本時間の開始・終了と対象を選び、保存します。
3. 自動実行したい場合だけ有効にします。
4. 履歴と「記憶・知識 → AI更新案」を確認します。

初期OFF、標準時間帯は00:00～07:00です。日付をまたぐ時間帯も設定できますが、開始と終了を同じにはできません。アプリと会話モデルの起動中に対象ごと一晩1回処理し、過ぎた夜の埋め合わせはしません。

通常は確認待ち案を作ります。「作成した夜間整理案を自動保存する」は独立した初期OFF設定です。索引更新も別設定です。古い案を後から一括承認する設定ではありません。

週次・月次圧縮は指定した終了済み期間を対象にします。複数ファイル集約は明示選択した入力を使い、新しい保存先を作り、元資料を保持します。

研究の同名統合、エンティティの重複整理・休眠にも独立した設定があります。「夜間の自動実行」だけを変更して一括で制御したつもりにならず、各欄を確認してください。

## タイマー・アラーム・行動予約

「世界・生活 → 時間・通知」で登録・状態確認・取消を行います。

| 種類 | 目的 |
| --- | --- |
| 通常のタイマー・アラーム・ポモドーロ | 期限到達時にアプリ内通知を保存 |
| 行動予約・AIアラーム | 目的・詳細・文脈を保持し、指定時刻に自律実行を予約 |

行動予約の曜日は日本時間です。停止中に過ぎた通常通知は、次回起動後に遅れを伴って記録される場合があります。行動予約もキュー投入と実行完了は別です。繰返しの過去分を連続再生するわけではありません。

Windows通知は対応する通知設定・環境が必要です。アプリ内通知が保存されたことと、OSの画面へ実表示されたことを区別してください。

手紙・短いお知らせは上部の「手紙箱」「通知」、または「世界・生活 → 手紙・お知らせ」で確認できます。外部配信とは別で、既読・未読は画面の操作で管理します。
