# ルーム別設定の使い方

2026年10月31日版。

[ユーザーガイド](USER_GUIDE.md) / [共通設定](COMMON_SETTINGS.md)

右上のROOMで選んだルームについて設定します。切替前に変更を保存または破棄してください。会話APIと外観以外にも、記憶・生活・自律・添付・外部アカウント等をルーム別に管理します。

## ルーム別メニューの一覧

| メニュー | 主な操作 |
| --- | --- |
| 会話 | 通常会話、画像入力、ユーザー本文の修正、再生成、選択以降の削除 |
| 記憶・知識 | 指示/記憶/ノート、検索、話題、記憶草案、整理/統合 |
| 世界・生活 | 所持品、衣装、場所/背景、時間/通知、手紙、生成画像 |
| 自律行動 | 活動目的、目標/研究/問い、実行設定、実行履歴、書き置き |
| 会話ログ | 前後を含む閲覧、検索、編集、退避した会話の復元 |
| ルーム設定 | 接続の上書き、Persona Contract、アバター、添付、索引、権限等 |
| 外部接続 | X、Discord、Googleカレンダー、Gateway／Liteのルーム別設定 |

個人の会話はSQLiteでルームを区別して保存します。ルームごとに別のSQLiteファイルを作る構成ではありません。記憶ファイル等は `app/characters/<ルーム名>` にあります。

## ルーム設定の各サブタブ

### 会話API

通常は「共通設定に従う」を使います。このキャラだけ接続を変える場合はチェックを外し、接続方式・キー・モデルを指定して「このルームの接続を保存」を押します。

共通キーをこのルームへ複製しなくても継承できます。共通を変更したとき追従させたい場合は継承を残してください。外部APIの接続を変えても、背景の自律/記憶整理用モデルまで自動で切り替わるわけではありません。

### Persona Contract

名前、ユーザーの呼び名、推奨/禁止表現、用語、口調ルール等を項目ごとに設定します。保存した条件で文章を検査できます。文字の一致や不在の検査であり、口調や人格の意味全体を判定したり、自動修正したりする保証ではありません。

### アバター・表情

profile / idle / thinking / neutral、joy / anger / anxious / sadnessの順に4列×2行で登録します。通常の待機はidle、生成中はthinking。回答後の自動切替はモデルの表情出力にも依存します。

対応画像がなければprofile等へ代替し、候補がなければ装飾記号になります。削除は管理上の非表示化です。[世界・生活と外観](WORLD_AND_APPEARANCE.md)に画像の条件と優先順位があります。

### 添付画像

このルームで送った画像を選んでプレビュー、元の発言表示、再添付、会話から外す/戻す、継続添付、退避・復元等を行います。選ぶだけでは送信しません。画像本体の完全削除と会話から外す操作は別です。[画像と添付](IMAGES_AND_ATTACHMENTS.md)を参照してください。

### 記憶索引

共通の検索モデルを使い、このルームの資料を索引化します。資料を変更した場合は更新してください。「保存後の索引更新」は独立した設定で、本文保存と索引完了は別に確認します。

検索方式や資料の送り方は「記憶・知識 → RAG・意味統合」、実際の検索は「検索」で確認します。

### ツール権限

カテゴリ別の許可、個別の確認待ち、実行結果を管理します。参照・確認待ち案・直接更新・外部送信を区別してください。ツール一覧をモデルへ提示しても、実際に呼ぶかどうかはモデルにも依存します。

許可を変えるだけで外部アカウントの接続や自律行動が一括で有効になるわけではありません。[ツールと外部接続](TOOLS_AND_CONNECTIONS.md)を参照してください。

### URL監視

このルームのURL、取得方針、要約、通知の条件を保存します。Web利用許可と接続設定も確認します。取得・要約・通知は別の結果として履歴を確認してください。

### 夜間の記憶整理

標準時間帯は日本時間00:00〜07:00、初期は無効です。対象・時間帯を保存し、自動実行したいときだけ有効化します。通常の自律行動とは別の機能です。

整理案の作成と原本への自動保存、索引更新もそれぞれ別設定です。[自律行動と予約](AUTONOMY_AND_SCHEDULES.md)に手順があります。

### 外観

変更したい項目だけルーム用の値を選びます。「共通を使う」の項目は共通設定に追従します。設定を選んだ後は保存してください。

## 外部接続のルーム別設定

| サブタブ | このルームで決めること |
| --- | --- |
| X / Twitter | 1アカウントの登録・認証、利用許可、取得/送信案等 |
| Discord | 1Botの登録・認証、対象チャンネル、受信方式、自動返信等 |
| Googleカレンダー | 共通の認証を使う許可、カレンダーID、取得/予定案等 |
| Gateway／Lite | 共通Gatewayから、このルームへアクセスできる条件 |

XとDiscordは、共通へ複数登録して選ぶ方式ではありません。一つのルームで複数アカウント/Botを同時に使いません。他ルームとの同一アカウント・Bot/チャンネルの重複確認は利用できます。

送信案を作っただけでは送信完了ではありません。Discord自動返信を明示的に有効化した場合は、個別の確認を待たず送る経路があるため、対象・条件を確認してから使います。
