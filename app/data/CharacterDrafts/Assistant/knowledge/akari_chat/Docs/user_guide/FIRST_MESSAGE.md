# 最初のメッセージと初期会話ログ

2026年10月31日版。

[ユーザーガイド](USER_GUIDE.md) / [ルームと会話](ROOMS_AND_CHAT.md)

最初の発言をファイルで用意する方法と、キャラ作成後にAIから話しかけてもらう方法があります。

## ファイルで用意する

配置先は次のとおりです。

```text
app/characters/<ルーム名>/data/Init_Msg.txt
```

```text
## AGENT:キャラ名
はじめまして。今日は何を話しましょう？
```

USER / AGENT / SYSTEMの見出しで複数発言を記述できます。見出しなしの本文は、一つのキャラ発言になります。本文にMarkdownを使えます。

UTF-8（BOMあり/なし）・CP932に対応。ファイルは1MiB、200発言までです。

## 取り込まれるタイミング

会話のないルームで履歴を読むと、初回だけSQLiteへ取り込みます。空ルームを先に開いていても、まだ会話していなければ、後から置いたファイルを取り込めます。ファイルがない/空なら取り込み済みにはしません。

一度取り込むと、ファイルを編集・削除・置き直しても再取り込みしません。会話を削除しても初期ログを自動で戻しません。既存会話があるルームでは挿入を見送ります。

このファイルの編集は、既存のSQLite会話を修正する操作ではありません。現在の会話の修正は「会話ログ」で行います。

## 画面で編集・プレビューする

1. Start.bat内の`INIT_SETTING`をYまたはyにします。
2. アプリを終了し、Start.batから起動し直します。画面内の再起動だけではbatの変更は読み直されません。
3. 「共通設定 → ルーム管理 → ルーム一覧」で対象を選びます。
4. 「初期会話ログ（Init_Msg.txt）」に入力します。画面入力は4000文字までです。
5. 「最初のメッセージをプレビュー」で会話形式の見本を確認します。
6. 内容を確認して「変更を保存」を押します。

本文だけで保存するとAGENT見出しを付けてファイルへ保存します。既存の初期ファイルはバックアップして更新します。古いroom_config.jsonのfirst_messageは互換読取され、画面で保存し直すとファイルへ移します。

プレビューではファイルやSQLiteへ保存せず、AIも呼びません。INIT_SETTINGが無効でも、保存済み内容のプレビューは見られます。入力を変えると古いプレビューは閉じます。再試行ボタンはありません。

INIT_SETTINGは編集欄を使える条件です。ファイルの初回取り込み自体を有効/無効にするものではありません。

## キャラ作成でAIに始めてもらう

「ルーム管理 → キャラ作成」から新規作成したルームだけ、AI初回発言の待機対象になります。そのルームを選び、会話モデルの準備ができると生成します。新ルームの会話接続を使い、外部APIなら通常と同様に利用料金・制限が適用されます。

本文のある初期ログがあれば、そちらを優先して追加生成しません。通常のルーム作成・キャラ取込・既存フォルダの読込からAI初回発言を自動登録することはありません。

生成した初回発言はSQLiteに保存し、テンプレートファイルは勝手に作りません。内部の生成依頼をユーザー発言として保存することもありません。失敗・中止・結果不明では自動再送しません。初回発言の通常再生成は対象外です。

保存先はルーム内の `data/Init_Msg.txt` です。アプリ共通の `app/data` とは別です。旧 `logs/0000-00.log` をこの新しい場所へ自動移動・自動読込はしません。未取込の旧テンプレートを使う場合は、新しい保存先に配置してください。既存の取込済み記録は維持するため、パス変更による再取込は行いません。
