# ツールと外部接続

2026年10月31日版。

[ユーザーガイドに戻る](USER_GUIDE.md)

## AIがツールを使う条件

ツールは、記憶を読む、更新案を作る、Webを参照するなどのアプリ操作です。モデルのツール呼び出し対応、ルームの権限、接続先や対象資料の準備が必要です。

利用可能な定義は必要に応じて追加提示されます。能力の要求が成功しても、実際の作業が完了した意味ではありません。「アプリ設定 → 動作の確認」でツールの状態・結果を確認してください。

## カテゴリ別の権限

「ルーム設定 → ツール権限」でカテゴリごとの範囲を選び、保存します。

| 範囲 | 内容 |
| --- | --- |
| 停止 | 対象ツールを使わせない |
| 参照のみ | 読み取りを許可 |
| 参照・提案 | 読み取りと確認待ち案の作成を許可 |
| 参照・提案・直接更新 | 対応する直接更新も許可 |
| 毎回確認（個別申請） | ツール名・引数を指定した一回限りの承認を使う |

提案を許可しても、その提案の保存まで自動承認するわけではありません。Web参照など、読み取りでも外部通信を伴うものがあります。

この設定は、人の画面編集や自動検索・登録済み予約の一括停止スイッチではありません。自律行動には独自の許可も必要です。

## 個別の権限申請

1. 対象カテゴリを「毎回確認」にして保存します。
2. 通常会話でAIが申請を作ると、「個別の権限申請」に表示されます。
3. 理由・ツール名・引数を読み、一回承認または却下します。
4. 承認後、新しいメッセージで続きを伝えます。

**承認ボタンだけでは処理を開始しません。** 同じツール・同じ引数の一回の呼び出しに使います。期限は申請作成から1時間です。設定や定義の変更で無効になる場合もあります。

自律処理はこの一回承認を使って権限を拡張しません。失敗時の再試行も状態を確認してから新しい申請・承認を行います。

## Web検索・公開URL・PDF

「アプリ設定 → Web・画像生成」でDuckDuckGo、Google検索（Gemini）、Tavilyを選び、保存してから検索テストを実行できます。Google検索は共通のGemini APIキー、Tavilyはこの画面に登録したキーを使います。検索先は自動で切り替わりません。

検索語やURLは外部へ送信します。公開ページの取得には制限があり、ログインが必要なページや任意のローカルファイルを読める機能ではありません。公開PDFの本文抽出は別の処理・追加依存関係が必要になる場合があります。

検索結果がないことだけで「情報が存在しない」とは判断できません。失敗・追加確認・未設定などの状態も確認してください。

## URL監視

「ルーム設定 → URL監視」で表示名・公開URL・グループ・頻度・時刻・日次上限を設定します。初期は停止・手動のみです。

定期取得にはURLの有効化と、自律設定のWeb許可が必要です。通常の定期自律や会話モデルの起動自体は、単純な取得に必須ではありません。差分のAI要約などを使う場合は、追加の設定・モデル条件に従います。

「一度だけ取得」で確認し、初回基準保存・変更なし・変更あり・取得失敗を見分けます。止める場合は有効を外して保存、保管する場合は「停止して保管」を使います。

## 画像生成

1. 「アプリ設定 → Web・画像生成」で方式を選びます。
2. 接続先URL、モデル名、キー、必要な生成条件を設定し、保存します。
3. 「世界・生活 → 画像生成」で本文・対象・参照画像などを確認して生成します。
4. ジョブの状態と生成画像を確認します。

方式にはローカル（SD WebUI / Forge）、Gemini、OpenAI互換、Pollinations、Hugging Faceがあります。ローカル方式も対応する別の画像生成サーバーが必要です。

接続先ごとの対応形式・認証・利用枠に従います。会話APIの設定とは別で、会話モデルを起動しただけでは画像生成できません。プロンプト編集・生成予約・画像完成・背景への反映も別の操作です。

## 音楽検索

「アプリ設定 → 音楽検索」で推薦リンクのサービスを選びます。YouTubeは常に有効です。音楽推薦は検索リンクを案内するもので、実在確認・再生・サービスのログインを完了する機能ではありません。

## 外部接続の設定場所

| サービス | 設定場所と範囲 |
| --- | --- |
| X / Twitter | 「外部接続 → X / Twitter」。1ルーム1アカウントを登録・認証 |
| Discord | 「外部接続 → Discord」。1ルーム1Botを登録・認証 |
| Googleカレンダー | 共通の認証は「アプリ設定 → 外部連携」。利用許可・操作は「外部接続 → Googleカレンダー」 |
| Gateway／Lite | 共通のサーバー・HTTPS・トークンは「アプリ設定 → 外部連携」。ルームの許可は「外部接続 → Gateway／Lite」 |

XとDiscordを共通側へ複数登録してルームで選択する方式ではありません。アカウントID、Botのチャンネル、必要な権限をルームごとに確認します。「接続確認・他ルームとの重複を確認」で同一アカウントなどの警告を確認できます。

OAuthや専用ブラウザでのログインを使う場合は、画面の手順に従って認証し、完了後に状態を確認してください。アプリ内の対応実装があることと、各実アカウントでの接続成功は別です。

## 参照・送信案・実送信

外部接続では、参照と送信案の作成、確認後の送信を区別します。

1. 接続先とルームの利用設定を保存します。
2. 画面または許可されたAIツールで参照・送信案の作成を行います。
3. 送信先、本文、日時、添付、変更・削除対象を確認します。
4. 確認チェックと承認操作で実行します。
5. 履歴と必要に応じて外部サービス側で結果を確認します。

設定変更後の古い案は使えない場合があります。通信断などの「結果未確認」は自動再送しません。まず実サービス側を確認し、重複投稿・重複予定を避けてください。

Discordの受信開始・停止、REST受信／Gateway接続、自動返信はそれぞれ状態を確認します。**自動返信を明示的に許可した場合は、個別の送信確認を待たずに返信する経路があります。** 自動返信は初期OFFです。同一Bot・同一チャンネルの競合も確認してください。

## 認証情報と移設

会話APIや外部連携の対象認証情報はWindowsユーザー向けの暗号化を使います。別PC・別Windowsユーザーへコピーしても、そのまま使えないため再認証が必要です。画像生成など、別方式の保存もあるので設定フォルダ全体を秘密情報として扱ってください。

Gatewayは外部クライアント用です。通常の会話だけなら有効化は不要です。トークン・HTTPS・公開範囲・ルーム許可を確認してから利用します。
