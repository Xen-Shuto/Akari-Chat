# はじめに・起動と終了

2026年10月31日版。

[ユーザーガイドに戻る](USER_GUIDE.md)

ソースのみの `Akari-Chat_Clean` は、Python・モデル・推論実行ファイルを別途準備します。[ソース版の準備](SOURCE_SETUP.md)を参照してください。以下は必要な実行環境を揃えた構成の説明です。

## 必要な環境

| 項目 | 内容 |
| --- | --- |
| OS | Windows 11 |
| Python | CPython 3.10.11（64bit）を採用・同梱 |
| ブラウザ | Chrome、Edge、Firefoxなど |
| ローカル会話モデル | llama.cppが対応するGGUFを別途用意 |
| GPU・メモリ | モデルと設定に応じたRAM・VRAM。GPU利用時は対応ドライバー等 |

同梱Pythonを使用しますが、別PCでのランタイム依存関係を含む配布環境の検証は完了していません。同梱Pythonがない場合、起動バッチは導入済みの `python` を使用します。書き込みが拒否された場合にも、導入済みPythonへ切り替える起動経路があります。

## フォルダ構成

```text
Akari-Chat/
├─ Start.bat             起動用
├─ README.md             アプリの概要
├─ Docs/                 ユーザーガイド
├─ llama.cpp/            推論エンジンと関連ファイル
├─ Models/               会話用・検索用のGGUFなど
└─ app/
   ├─ runtime/           同梱Python
   ├─ characters/        キャラクター設定・記憶など
   ├─ data/              会話DB・設定・添付画像・ログなど
   ├─ tools/             アプリのツール実装
   └─ web/               ブラウザ画面
```

アプリが書き込める場所へ配置します。モデルは外部フォルダに置いてパスを指定することもできます。

## 起動する

1. `Start.bat` をダブルクリックします。
2. コンソールが開き、ブラウザに画面が表示されるまで待ちます。
3. 自動でブラウザが開かない場合は、コンソールの表示URLを確認します。標準ポートは `8765` です。
4. [モデルと共通設定](MODELS_AND_SETTINGS.md) に従って会話モデルを準備します。
5. [ルームと会話](ROOMS_AND_CHAT.md) に従ってキャラクターを選びます。

画面はモデルの準備完了を待たずに開きます。画面が見えていても、読み込み中はまだ生成できません。「次回起動時にモデルを自動起動」が保存済みなら、次回から自動起動します。

同じインストールの二重起動はできません。すでに起動している場合は既存の画面を利用してください。

## 終了・再起動する

上部の終了アイコンを **1秒長押し** すると終了します。コンソールの `Ctrl+C` でも終了できます。ブラウザのタブを閉じるだけでは、アプリやモデルは終了しません。

再起動アイコンも **1秒長押し** です。保存済み設定で起動し直し、通常は同じブラウザタブを再読み込みします。

**長押しの終了・再起動では、未保存の本文や設定を保存する確認は出ません。未保存内容は破棄されるため、必要な内容を先に保存してください。** 実行中の生成には停止処理が入り、管理中の会話用・検索用モデルも終了対象になります。

コンソールの「×」や強制終了では、生成途中の本文が保存される保証はありません。通常の終了操作を使ってください。

## 自動起動やポートの問題を避けて開く

モデルの自動起動で問題が出る場合は、`Akari-Chat` でターミナルを開いて実行します。

```powershell
.\Start.bat --no-auto-start
```

保存済み設定は変更せず、今回のモデル自動起動を省略します。画面からパスや設定を見直せます。

標準ポートが他のアプリで使用中の場合は、別ポートを指定できます。

```powershell
.\Start.bat --port 8766
```

ポートを変えても同じインストールの二重起動制限は解除されません。
