# あかりチャット ユーザーガイド

2026年10月31日版。現在の画面に合わせて、共通設定とルーム別設定、日常の操作を案内します。

あかりチャットは **NexusArkの下位互換として開発しているアプリケーション**です。全機能の再現・完全互換を保証するものではありません。概要と謝辞は[README](../README.md)をご覧ください。

## 最初に読む

1. [起動と終了](GETTING_STARTED.md)で必要な環境と起動方法を確認します。ソース構成だけを入手した場合は、先に[ソース版の準備](SOURCE_SETUP.md)を読みます。
2. [共通設定](COMMON_SETTINGS.md)で会話モデルまたは会話APIを準備します。
3. [ルームと会話](ROOMS_AND_CHAT.md)でキャラを作成・取り込みします。
4. [ルーム別設定](ROOM_SETTINGS.md)でキャラごとの記憶・権限・外観を調整します。

## 共通とルーム別を使い分ける

右ペインのROOMで会話するルームを選びます。その下の「ルーム別設定」「共通設定」でメニューの範囲を切り替えます。左はキャラと現在地、中央は選んだ画面です。長いサブタブは横スクロールできます。

| 範囲 | メインメニュー | 扱うもの |
| --- | --- | --- |
| ルーム別設定 | 会話 | 選択ルームの会話・画像入力 |
| ルーム別設定 | 記憶・知識 | 指示・各種記憶・検索・整理・AI更新案 |
| ルーム別設定 | 世界・生活 | 所持品・衣装・場所・背景・予約・手紙・生成画像 |
| ルーム別設定 | 自律行動 | 活動・実行設定・研究・履歴 |
| ルーム別設定 | 会話ログ | 発言の検索・編集・復元 |
| ルーム別設定 | ルーム設定 | 会話APIの上書き・Persona Contract・表情・索引・権限・夜間整理・外観 |
| ルーム別設定 | 外部接続 | X / Twitter・Discord・Googleカレンダー・Gateway／Liteのルーム側設定 |
| 共通設定 | グループ会話 | 参加キャラを選ぶ独立した会話 |
| 共通設定 | 共有データ | 共有手順・共通クローゼット |
| 共通設定 | ルーム管理 | 作成・保管・復元・キャラ取込・NexusArk書出し |
| 共通設定 | アプリ設定 | 会話/検索モデル・標準API・音楽検索・共通接続・動作確認・外観 |

会話APIは「ルーム独自の接続」が共通設定より優先されます。外観は上書きした項目だけルームを優先します。すべての設定に共通とルームの両方があるわけではありません。X/Discordのアカウント登録はルーム内で完結します。

ルーム管理には独立した対象選択があります。右のROOMだけを見ず、操作画面の対象も確認してください。

## 保存・提案・実行の違い

入力しただけでは保存されない設定があります。画面の保存ボタンと完了表示を確認します。AI更新案は確認待ちの内容で、保存済み本文とは別です。自動保存は各機能の独立した設定に従います。

予約の受付は処理完了ではありません。AIの返答だけで操作成功と判断せず、ツール履歴・保存先・外部サービスの結果を確認します。「結果未確認」は成功でも失敗でもありません。

会話を編集・復元しても、記憶更新や外部送信まで一括で巻き戻るわけではありません。終了/再起動を長押しすると未保存の編集は破棄されるため、必要な内容を先に保存してください。

## 表示とデータ

会話・会話ログ・初期ログのプレビューはMarkdown表示に対応します。編集・保存・書出しは元の文章を保持します。Markdown内の画像は自動取得せず、添付画像は別に管理します。

会話は `app/data/` のSQLite、キャラ設定・記憶は `app/characters/` 等で管理します。キャラフォルダだけのコピーは、アプリ全体のバックアップにはなりません。

パスは原則としてAkari-Chatフォルダを基準にしています。本ガイドはソースと既存検証に基づく操作案内で、全モデル・別PC・外部サービスの実認証・長期運用・NexusArk完全往復を検証済みとするものではありません。
