# あかりチャット（Akari-Chat） v0.1.4_β

**～　呼びかけたら返事してくれそうな、キャラとの会話に、小さな灯りがともりますように。　～**
##  
AIキャラクターとの会話や、記憶・世界観の管理を楽しむための、Windows向けチャットアプリケーションです。

**あかりチャットは、NexusArkの下位互換として開発しているアプリケーションです。**

ケノさんが開発された [NexusArk（Nexus Ark）](https://github.com/kenomendako/Nexus-Ark) を参考に、キャラクターとの対話を中心とした機能を実装しています。NexusArkの豊富な機能や、AIペルソナの生活・成長を支える仕組みのすべてを再現するものではありません。

> **開発中のアプリケーションです。**
> 機能や画面は変更されることがあり、不具合が残っている可能性があります。大切なキャラクターや会話データは、バックアップを保管してください。

## あかりチャットについて

キャラクターの設定や記憶をもとに会話し、そのやり取りを振り返りながら、キャラクターとの時間を重ねていくことを目指しています。

ローカルLLMにはllama.cppを利用し、アプリから推論サーバーを起動・停止できます。会話用の外部APIを設定して利用する機能も備えています。

## NexusArkとの関係

**あかりチャットの位置づけは、NexusArkの下位互換です。** NexusArkの機能全体や動作をそのまま利用したい場合は、[NexusArk本体](https://github.com/kenomendako/Nexus-Ark) をご覧ください。

- NexusArkのキャラクターフォルダを、原本を変更せずにコピーして取り込めます。
- キャラクター設定、記憶、会話ログなど、対応しているデータを利用できます。
- NexusArk向けのキャラクターフォルダ書き出し機能があります。
- **データの互換性は一部に限られます。** すべての設定・機能・内部状態の継承や、完全な往復互換を保証するものではありません。書き出したデータのNexusArk上での実動作確認も、まだ完了していません。

ここでいう「下位互換」は、NexusArkを参考に機能を絞って実装しているという位置づけを示します。全データ形式の完全互換を意味するものではありません。

## 主な機能

- **キャラクターとの会話**：キャラクター設定や記憶を使った会話、履歴の保存・編集、返答の再生成、グループ会話。
- **ローカルLLMの管理**：GGUFモデルの選択、推論サーバーの起動・停止、モデルや生成条件の設定。
- **会話用の外部API**：OpenAI、Gemini、Anthropic、OpenAI互換APIへの接続設定。
- **画像を添えた会話**：画像入力に対応するモデル・接続先での画像付きメッセージ。
- **記憶・知識の管理**：指示や記憶の編集、会話からの記憶作成、キーワード検索・意味検索。
- **世界観と外見の管理**：世界設定、現在地、背景、所持品、衣装、アバターなどの管理。
- **ツールと外部連携**：設定と権限に応じたツール実行や外部サービスとの連携。

利用できる機能は、モデルの能力や接続先、追加設定によって異なります。外部APIや外部サービスの利用には、それぞれのアカウント・APIキー・利用料金が必要になる場合があります。

## 動作環境

| 項目 | 環境 |
| --- | --- |
| OS | Windows 11 |
| Python | **CPython 3.10.11（64bit）**を同梱 |
| ブラウザ | Chrome、Edge、Firefox など |
| ローカルLLM | 使用するGGUFモデルを別途用意。画像入力には、対応モデルと必要に応じて対応するmmprojが必要 |
| メモリ・GPU | 使用するモデルや設定に応じたRAM・VRAMが必要 |

ローカルLLMの動作条件は、使用するllama.cppのビルドとモデルによって異なります。GPUを使用する場合は、対応するドライバーなどの実行環境が必要です。

Python・追加機能用ライブラリ・llama.cppの実行ファイルは同梱します。**GGUFモデルは別途用意してください。** 初めて使う場合は、[利用準備と更新](Docs/user_guide/INSTALLATION.md)を確認してください。

## データについて

アプリ本体と利用データは、基本的に `Akari-Chat` フォルダ内で管理します。

| 保存先 | 内容 |
| --- | --- |
| `Akari-Chat/app/characters/` | キャラクター設定や記憶などのファイル |
| `Akari-Chat/app/data/` | 会話データベース、アプリ設定、添付画像、ログなど |
| `Akari-Chat/Models/LLM/` | 会話用GGUF。サブフォルダ可 |
| `Akari-Chat/Models/embeddings/` | 記憶検索用のモデルファイル |
| `Akari-Chat/Exports/NexusArk/` | NexusArk向けに書き出したキャラクターフォルダ |

モデルには外部フォルダのファイルを指定することもできます。キャラクターフォルダだけでは、あかりチャットで保存した会話や設定のすべてを保管できないため、バックアップ時には会話データベースなども含めてください。
